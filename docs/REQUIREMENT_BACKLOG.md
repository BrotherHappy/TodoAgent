# Requirement Backlog

这是 Team 模式的共享需求队列，供 Product / UX / QA Agent（Agent A）持续写入，供 Engineering / Documentation Agent（Agent B）按优先级消费。

## 协作规则

- Agent A 只做真实用户视角的体验、复现、验收和需求记录，不修改业务代码。
- Agent B 按 `P0 → P1 → P2` 处理未完成项；完成后必须附测试证据、文档同步说明和验收入口。
- Agent A 对 B 的完成项实际运行验收：通过标记 `Accepted`，失败补充复现步骤并回到队列。
- Team Lead 负责去重、拆分依赖、确认范围；当前范围只覆盖桌面端，不新增手机端工作。
