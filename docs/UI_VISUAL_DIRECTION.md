# TODO Agent 视觉设计规范 v1.0

> 对应文档：[PRD.md](./PRD.md)、[UX_INFORMATION_ARCHITECTURE.md](./UX_INFORMATION_ARCHITECTURE.md)<br>
> 参考方向：[浮引 · FloGravity Mac](https://fg.vkr.me/mac)<br>
> 适用范围：Windows / macOS 桌面端 P0，兼顾未来 iOS / Android 迁移<br>
> 原则：借鉴其轻盈、原生、悬浮和快捷入口语言，不复制品牌、图标、素材或界面布局。

## 1. 视觉目标

这不是传统“后台管理式”待办工具，而是常驻桌面的个人任务伴侣。视觉需同时表达四件事：

1. **近**：当前任务和录入入口像桌面组件一样随手可达。
2. **轻**：大面积留白、半透明材质与低噪声层级，让常驻界面不造成压力。
3. **活**：Agent 有温度，但不以拟人装饰抢占任务主体。
4. **可信**：同步、权限、外部写入和恢复路径必须比装饰更清楚。

一句话风格定义：

> 原生桌面小组件的轻盈材质 + 启动器的键盘效率 + 任务工具的可靠反馈。

## 2. 从参考产品提炼的设计语言

### 2.1 保留的特征

- 大圆角、悬浮于桌面之上的独立面板。
- 由背景内容产生的柔和玻璃材质，而非生硬的纯灰卡片。
- 高密度功能通过规则网格、分组和快捷键建立秩序。
- 控件尺寸舒展，图标使用圆角方形底座，降低工具感的冷硬程度。
- 搜索、模式切换和设置聚合在面板上沿，核心内容保持干净。
- 通过少量蓝紫、橙和薄荷色区分功能，不把每个项目都染成不同颜色。
- 悬浮窗、桌面组件和主应用共享同一视觉家族。

### 2.2 不直接沿用的部分

- 不使用参考产品的标志、品牌渐变、应用图标或宣传图片。
- 不把待办列表改造成应用启动器网格；任务仍以可扫描的纵向列表为主。
- 不用玻璃效果弱化文字、风险和同步状态。
- 不为了“像 macOS”而牺牲 Windows 的系统习惯和可访问性。

## 3. 设计原则

### 3.1 任务事实第一

- Today 是默认首页，任务标题拥有最高阅读优先级。
- Agent 建议、晨间总结和装饰背景不能推低第一屏的任务数量。
- 当前任务以尺寸、位置和轻微强调表达，不只依赖颜色。

### 3.2 三层连续体验

```text
悬浮胶囊  →  迷你面板  →  完整主应用
一件事        今天 / 对话      全量管理
```

三层使用同一任务标题、来源标识、完成状态与 Agent 状态；展开时保持视觉锚点连续。

### 3.3 玻璃是材质，不是信息层级

- 玻璃只用于应用窗口、悬浮胶囊、弹层和桌面组件。
- 列表行主要靠间距与细分隔线组织，避免“卡片套卡片”。
- 高风险确认使用较实的表面和清晰边框，不能透明到与背景混合。

### 3.4 色彩有职责

- 品牌强调：靛紫 / 天空蓝。
- 本地任务：中性墨色 + 设备图标。
- 飞书任务：蓝色 + “飞书”文字标签。
- 成功：薄荷绿；提醒：暖橙；危险：红色。
- 红色只用于逾期、错误、不可逆或高风险，不作为普通品牌色。

## 4. 视觉令牌

### 4.1 色彩

| 角色 | 浅色建议 | 深色建议 | 用途 |
|---|---:|---:|---|
| 桌面底色 | `#E9EEF5` | `#0B0D14` | 抽象壁纸、窗口外环境 |
| 珍珠玻璃 | `rgba(250,252,255,.78)` | `rgba(24,26,36,.82)` | 主窗口、迷你面板 |
| 实体表面 | `#F9FAFC` | `#1A1D27` | 详情、确认、输入区 |
| 主文字 | `#171922` | `#F5F6FA` | 标题、任务正文 |
| 次文字 | `#666B78` | `#A9AEBA` | 辅助信息 |
| 分隔线 | `rgba(30,35,50,.10)` | `rgba(255,255,255,.12)` | 边框、分组 |
| 主强调 | `#6E6AF6` | `#9B98FF` | 选中、主要动作、Agent |
| 辅助强调 | `#74B6FF` | `#79BAFF` | 飞书、同步、链接 |
| 成功 | `#2FA97D` | `#65D7AD` | 完成、同步成功 |
| 提醒 | `#E58B39` | `#FFB66E` | 临期、需要注意 |
| 危险 | `#D94B55` | `#FF7D87` | 错误、高风险、停止 |

大面积渐变仅用于抽象桌面背景和 Agent 氛围光：靛紫、天空蓝、淡粉三色低饱和叠加。正文表面保持中性。

### 4.2 字体

- macOS：优先使用 SF Pro / 系统字体。
- Windows：优先使用 Segoe UI Variable / 系统字体。
- 中文回退：PingFang SC、Microsoft YaHei。
- 标题字重 500，正文 400，关键数字最高 500；避免大量粗体。
- 任务标题 14–16 px；详情标题 20–24 px；晨间问候 28–32 px。
- 次要文字不得小于 11 px，常规辅助文字建议 12–13 px。

### 4.3 圆角

| 对象 | 圆角 |
|---|---:|
| 主窗口 / 大浮层 | 28–32 px |
| 迷你面板 / 对话框 | 22–26 px |
| 桌面组件 | 22–28 px |
| 输入框 / 工具条 | 14–18 px |
| 图标底座 / 小卡片 | 12–16 px |
| 状态标签 | 999 px |

圆角随层级递减，不让所有元素都成为同样的“药丸”。

### 4.4 阴影与描边

- 主窗口：`0 28px 80px rgba(20,26,45,.18)`。
- 悬浮胶囊：`0 16px 44px rgba(20,26,45,.20)`。
- 内高光：顶部 1 px 半透明白线，强化玻璃边缘。
- 深色模式降低外阴影，提高边框和内高光可见度。
- 当前任务可用 1 px 强调描边，不用厚重投影。

### 4.5 间距与密度

- 基础单位 4 px；常用间距 8 / 12 / 16 / 24 / 32 px。
- 任务行最小高度 48 px，触控目标最小 44 × 44 px。
- 主应用桌面端保持三栏：导航 176–208 px、列表自适应、详情 256–320 px。
- 迷你面板宽度建议 340–380 px；快速录入宽度建议 560–680 px。

## 5. 核心组件

### 5.1 悬浮胶囊

- 收起态只显示 Agent 状态光点、当前任务、剩余时间和展开按钮。
- 单击展开，拖动空白区域移动；靠屏幕边缘自动吸附。
- 任务完成后在原位置出现勾选和“已同步 / 待同步”，随后再收起。
- Agent 需要确认时，光点变暖橙并显示“1 项待确认”；高风险时显示文字，不能只变色。

### 5.2 迷你面板

- 顶部为 Today / 对话 / 动态分段切换。
- Today 默认显示 3–5 项，来源与时间在右侧，完整标题优先。
- 底部固定快速输入；输入自然语言后在原处出现解析 Chip。
- “在主应用打开”保持在页脚，进入后保留当前任务或对话语境。

### 5.3 快速录入

- 采用居中、接近系统 Spotlight 的宽输入窗。
- 输入区下方显示结构化解析结果：标题、时间、清单、来源、提醒。
- 最终按钮明确写“保存到本地”或“创建到飞书”，不使用含糊的“确认”。
- Agent 指令与普通新建通过语义识别切换，但始终显示即将执行的动作。

### 5.4 Today 主应用

- 左栏采用半透明导航，选中项为低饱和靛紫底。
- 中栏顶部是短晨间总结，下面直接进入任务列表。
- 任务行使用复选框、标题、来源、私人计划 / 截止信息；逾期以文字和图标提示。
- 右栏展示任务详情，飞书字段与私人计划分区，避免误解回写范围。
- 窗口上沿聚合搜索、同步状态、Agent 状态和新增按钮。

### 5.5 Agent 工作台

- 对话为主栏，当前上下文与运行状态为窄侧栏。
- Agent 使用柔和的靛紫光晕和小型星轨图标，不使用大型拟人头像。
- 批量修改先展示“影响数量、来源、原值 → 新值、跳过项”。
- 研究和行动在视觉上分成两个阶段；研究结果不直接带写入完成态。

### 5.6 权限与高风险确认

- 确认面板使用更实的背景，悬浮在任务或 Agent 界面上方。
- 首行使用动词描述动作，例如“向飞书更新 12 个任务”，而不是“需要权限”。
- 固定展示：目标、数据范围、网络目标、文件 / 系统写入、外部影响、可逆性。
- 标准模式的高风险授权默认只有“仅本次”；全权限开启需身份验证、范围和有效期。
- “停止 Agent”是持续可见的独立危险动作。

### 5.7 同步与冲突

- 顶栏仅展示聚合状态；具体错误进入同步问题页。
- 冲突对比使用并排或逐字段布局，清楚标出本地值、飞书值和私人计划。
- 解决入口为“保留本地”“采用飞书”“逐字段选择”，并说明是否会回写。

## 6. 动效

- 悬浮胶囊展开：180–220 ms，弹性很弱，保持稳定。
- 窗口 / Sheet 出现：160–200 ms，位移 8–12 px + 透明度。
- 任务完成：勾选即时响应，文字 120 ms 变为完成态，同步状态独立更新。
- Agent 思考：低频柔和呼吸，不循环旋转大型装饰。
- 长任务进度：真实步骤推进，不用无意义无限加载。
- 尊重“减少动态效果”；关闭后只保留状态切换，不做位移和呼吸。

## 7. 跨平台适配

### macOS

- 使用交通灯、菜单栏入口、桌面小组件与系统材质习惯。
- 快捷键显示 `⌘` / `⌥` / `⌃`。
- 面板避让菜单栏和 Dock。

### Windows

- 使用标准标题栏按钮、系统托盘入口与 Windows 通知习惯。
- 快捷键显示 `Ctrl` / `Alt` / `Win`。
- 玻璃效果依赖系统支持；关闭透明效果时回退为不透明实体表面。
- 面板避让任务栏、多显示器工作区和系统安全桌面。

### 移动端预留

- 桌面三栏依次降级为导航页 → 任务列表 → 详情页。
- 悬浮胶囊对应系统小组件 / Live Activity / 通知快捷操作。
- Agent 高风险授权必须进入完整页面，不在小组件内完成。

## 8. 可访问性

- 文本与实际背景对比度至少满足 WCAG AA。
- 来源、风险、同步和权限状态必须同时有文字或图标，不只靠颜色。
- 完整支持键盘导航、清晰焦点环和屏幕阅读器标签。
- 200% 字体下不裁切任务标题、确认动作和错误信息。
- 高对比度模式关闭玻璃透射，改用实体表面和更强边框。

## 9. 首轮视觉验收清单

- [ ] Today 第一屏无需滚动即可看到晨间摘要和至少 4 个任务。
- [ ] 悬浮胶囊、迷你面板、主应用能识别为同一产品。
- [ ] 本地 / 飞书来源在任务、预览、详情和通知中一致。
- [ ] 私人计划与飞书截止不会被误认为同一字段。
- [ ] 全权限、待确认、离线和冲突始终有稳定入口。
- [ ] 高风险确认可在 5 秒内读懂“做什么、对谁做、能否恢复”。
- [ ] 320 px 宽度无横向溢出；桌面窗口在 736 px 宽度可完整理解。
- [ ] 深浅色、减少动画、关闭透明效果均有可用回退。
- [ ] Windows 与 macOS 只改变系统习惯，不改变任务和权限语义。
