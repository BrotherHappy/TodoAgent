# Todo Pet 动作与互动设计规范

> 状态：核心行为层已实施
> 适用产品：Todo Agent 桌面端
> 最近更新：2026-08-15

## 1. 设计目标

Todo Pet 不是任务列表旁边的动画装饰，而是任务事实、专注状态、飞书同步和 Agent 执行过程的身体化入口。

本规范解决四个问题：

1. 宠物在没有任务操作时也有自然、克制的生命感。
2. 用户能通过动作判断宠物正在专注、同步、思考、执行或等待确认。
3. 用户可以直接抚摸、玩耍和休息，但不会因此承担喂养压力。
4. 动作不会盖过任务、打断专注或伪装真实执行结果。

## 2. 体验原则

### 2.1 任务行为驱动生命感

任务完成、专注、同步和 Agent 工具状态是动作的首要来源。随机动作只在系统空闲时出现。

### 2.2 正向养成，不惩罚离线

互动可以增加亲密度，但不互动不会扣分。宠物不会饥饿、生病、离家或责怪用户。

### 2.3 动作可解释

每个自动动作必须表达以下至少一种含义：状态、反馈、提醒、关系。只为热闹而播放的动画不进入默认动作集。

### 2.4 注意力有预算

- 微动作默认间隔 8-20 秒，鼠标悬停和面板展开时仍可继续，但不重复弹话。
- 主动文字必须服从安静时段、专注模式、提醒开关和主动程度。
- 专注、同步、Agent 执行和权限确认期间，不播放随机动作。
- 减少动画模式下固定为静态姿势，关键信息仍通过文字和图标表达。

## 3. 行为状态机

动作优先级从高到低如下：

1. 减少动画降级
2. 等待权限确认
3. Agent 思考或执行
4. 飞书同步
5. 专注或休息
6. 到期提醒
7. 用户直接互动或任务完成反馈
8. 随机日常动作
9. 安静待机

高优先级动作可以打断低优先级动作。权限确认、Agent 执行和飞书同步不会被随机动作或玩耍覆盖。

## 4. 核心动作词典

宠物使用头、身体、耳朵、眼睛、瞳孔、双臂、双脚和尾巴组成的矢量骨骼。动作直接改变身体姿态，不以图标贴纸代替运动。

### 4.1 二十种待机动作

`idle` 呼吸眨眼、`wave` 招手、`stretch` 伸懒腰、`yawn` 哈欠、`nap` 小睡、`read` 看书、`play` 毛线球、`drink` 喝水、`look-left` 左看、`look-right` 右看、`head-tilt` 歪头、`tail-wag` 摇尾、`ear-twitch` 动耳、`sit` 坐下、`dance` 跳舞、`hum` 哼歌、`inspect` 放大镜观察、`tidy` 整理任务卡、`float` 漂浮、`peek` 探头。

动作包允许选择自然平衡、安静陪伴、活泼好奇和专注搭档。夜间自动使用更安静的子集；减少动态效果时保持静态姿势和文字等价反馈。

### 4.2 八种情绪

平静 `calm`、好奇 `curious`、开心 `happy`、兴奋 `excited`、专注 `focused`、困倦 `sleepy`、关心 `concerned`、自豪 `proud`。情绪分别控制眼睛、眉毛、嘴形、腮红和身体张力。

### 4.3 业务动作组

| 动作组 | 动作 | 身体语言 |
|---|---|---|
| 直接互动 | pet、poke、tickle、high-five、drag | 放松眯眼、惊讶后仰、发痒弹跳、举手击掌、被提起后落地 |
| 任务 | task-carry、task-drop、task-plan、task-complete、task-clear | 搬任务卡、接住卡片、整理计划、完成庆祝、清空自豪 |
| 专注 | focus、focus-paused、break | 戴耳机稳定呼吸、暂停等待、喝水伸展 |
| 同步 | sync、sync-success、sync-error | 搬运同步箱、送达庆祝、箱体抖动并关心提醒 |
| Agent | think、search、work、approve、agent-error | 思考、放大镜搜索、处理任务卡、抱住授权盾牌、失败恢复 |
| 通用反馈 | celebrate、alert | 成功跳跃、温和提醒 |

## 5. 任务与系统事件映射

| 事件 | 宠物动作 | 可见反馈 | 业务约束 |
|---|---|---|---|
| 新建任务 | 接受任务后 wave | “记下了” | 只在写入成功后反馈 |
| 完成任务 | celebrate | “完成一件，真不错。” | 飞书状态仍以同步回执为准 |
| 修改任务 | work | 修改后的标题 | 不从模型自然语言猜结果 |
| 删除任务 | approve 后 work | 确认与结果 | 遵循统一权限引擎 |
| 任务逾期 | alert | 延期、拆分、忽略建议 | 不责怪用户 |
| 专注开始 | focus | 耳机与倒计时气泡 | 计时服务是唯一事实来源 |
| 专注暂停 | stretch | 继续、结束 | 不丢失累计时间 |
| 专注休息 | break | 水杯与休息文案 | 到时仍由计时服务触发 |
| 飞书同步 | sync | 同步状态 | 不用开心动作冒充成功 |
| Agent 思考 | think | 流式回答 | 与真实运行状态绑定 |
| Agent 工具执行 | work | 工具状态 | 不暴露不必要参数 |
| 等待授权 | approve | 盾牌与确认按钮 | 宠物不能替用户确认 |
| 执行失败 | alert | 失败原因与重试 | 保留审计记录 |

## 6. 直接互动

### 6.1 默认手势

| 手势 | 行为 |
|---|---|
| 单击 | 播放问候并展开宠物面板 |
| 双击 | 打开主应用，并进入记住的页面 |
| 拖动底部把手 | 移动宠物窗口 |
| 右击 | 打开快捷菜单 |
| 悬停 | 达到设置延迟后展开，离开整个窗口后自动收起 |

### 6.2 轻互动菜单

宠物悬停时显示心形互动入口。单击后，八个操作围绕宠物形成环形轮盘，直接提供摸头、挠痒、击掌、毛线球、戳肚子、喝水、协作跳绳和镜像伸展。右键菜单继续提供任务和设置类快捷操作，但不再是互动的唯一入口。

环形互动与右键菜单共同提供：

- 摸摸宠物：播放 pet，记录每天一次的正向互动奖励。
- 玩一会儿：播放 play，不打开大型小游戏。
- 一起休息：播放 drink，引导喝水和活动肩膀。
- 在此处对话：保留在小窗口内聊天，支持 Markdown 和流式回复。

互动奖励使用每日、每种互动幂等键，避免刷点击获得无限成长。

### 6.3 协作小游戏

- 协作跳绳：20 秒一局，绳子到达脚边的绿色时机窗时，用户连续点击“起跳”；每次有效点击都会立即触发宠物跳跃反馈，并记录成功数、连跳和差一点次数。
- 镜像伸展：宠物依次示范抬肩、左右舒展和喝水，用户每完成一拍主动确认后才进入下一拍；不调用摄像头、不评价动作标准。
- 两种游戏均可随时退出，不产生惩罚、连胜压力或任务状态变更；完成记录进入本地宠物成长数据。

### 6.4 任务拖放互动

- 任务卡可以从全部或今天列表拖到宠物身体。
- 宠物在拖入时伸手接卡，放下后显示任务标题和“完成、今天、专注、放下”四个确定性操作。
- 完成和移入今天通过共享任务服务执行；飞书任务继续服从同步回执。
- 文本、URL、图片和文件拖放仍保留为未来 Agent 安全预览能力，不在本轮静默读取或写入。

### 6.5 动作物理与视觉因果

互动动画必须按“道具进入—发生接触—宠物反应—恢复待机”的顺序表达，不得用全身抖动或同一段跳跃替代不同语义。

| 互动 | 必须出现的因果关系 |
|---|---|
| 摸头 | 手掌从上方进入并接触头顶；头部轻压、闭眼、尾巴短暂加快 |
| 戳肚子 | 手指从侧面进入并接触腹部；接触点产生一次波纹，身体局部回弹 |
| 挠痒 | 羽毛接近身体侧面；宠物护住肚子并左右扭动，不做无方向震屏 |
| 击掌 | 用户手掌与抬起的宠物前爪在同一位置接触；身体只做轻微重心转移 |
| 玩球 | 球滚动和弹起；眼睛、头和前爪跟随球的位置，不做庆祝跳跃 |
| 喝水 | 前爪抬杯、杯沿靠近嘴部、头部轻倾，完成后回到站姿 |
| 拖动 | 身体被轻轻提起、双脚自然悬垂；禁止高速左右摇晃 |
| 跳绳 | 绳子具有前后遮挡层；脚边时起跳、身体越绳、绳子再从背后越过头顶 |

- 待机只保留轻微胸腹呼吸、随机眨眼、低频耳朵和尾巴反应；整个身体不得永久漂浮。
- 季节装饰不得作为不明圆点、月亮或轨道物常驻宠物身侧；季节表达放在小房间、服装或明确的节日动作中。
- 每个主动互动使用独立动作曲线，不能复用庆祝弹跳来冒充击掌、玩球或拖动。
- 动画只修改 `transform` 和 `opacity`，并在减少动画模式下稳定退化为静态姿势与文字反馈。

## 7. 主动陪伴

主动消息默认分为安静、均衡、活跃三级。系统同时满足开关、非安静时段、非专注、非全屏和频率预算时才显示。

推荐消息类型：

- 早晨任务摘要
- 即将到期提醒
- 长任务拆分建议
- 选择下一任务
- 久坐喝水和伸展
- 天气与出行提示
- 日终回顾

默认禁止：内疚文案、连续签到威胁、宠物生存压力、在会议或全屏演示期间说话。

## 8. 成长、冒险与持续内容

成长数据使用经验、等级、亲密度和五项能力属性。动作层不复制任务数据，也不因离线、逾期或中断扣除数值。

当前实现四条正向成长路径：

- 默契：直接互动和采纳建议。
- 专注：完成有效专注轮次。
- 探索：通过 Agent 学习和研究。
- 整理：完成任务、规划和复盘。

- 小房间：云朵工作室、森林角落、夜航书房；支持四套身体配色、四套服装和摆件组合并本地持久化。围巾与云灯为初始内容；冒险解锁探索帽、书架和观察动作；呼吸游戏解锁植物与茶杯；接星星解锁星光披风与舞蹈动作。
- 今日冒险：每天一个可选择的短篇，三种路线生成不同结果；不要求连续签到，完成后发放幂等奖励和冒险星。
- 共同日记：本地任务、专注和天气事实生成，可编辑、删除。
- 可控记忆：只有用户明确保存的内容进入长期记忆，可暂停、编辑、删除。
- 休息小游戏：16 秒呼吸引导、20 秒接任务星、20 秒协作跳绳和四拍镜像伸展；每天每种游戏只奖励一次，避免刷分。
- 季节事件：以小装饰和动作表现季节，不改变任务事实或成长效率。
- 动作包：平衡、安静、活泼、专注四套内置策略，共享同一状态机，保留继续扩展动作包的注册边界。

所有解锁和装饰都不能改变权限、任务、同步或 Agent 执行事实。

## 9. 无障碍与性能

- 宠物动作同时提供可访问名称。
- 所有互动按钮支持键盘焦点和屏幕阅读器。
- 动画只改变 transform 和 opacity，不持续修改布局。
- prefers-reduced-motion 下停用循环和自动动作。
- prefers-reduced-transparency 下使用实色气泡。
- 紧凑待机以低频 CSS 动画为主，不为随机动作持续启动 JavaScript 帧循环。
- 动作资源失败时回退到静态宠物，不回退悬浮球或胶囊。

## 10. 本轮验收标准

- [x] 20 种待机动作、8 类情绪和五组业务动作。
- [x] 宠物持续呼吸、双段随机眨眼，并由瞳孔跟随鼠标。
- [x] 点击头、肚子、手臂和下半身产生不同身体反馈与气泡。
- [x] Agent 思考、工具执行、权限确认具有不同身体语言。
- [x] 专注、休息、同步和逾期任务具有确定性映射。
- [x] 宠物周围提供八项可点击的环形互动，右键菜单作为备用快捷入口。
- [x] 协作跳绳包含时机窗、连续点击、连跳统计和宠物逐次反馈。
- [x] 镜像伸展包含四拍共同动作、逐拍确认与温和完成反馈。
- [x] 完成任务后播放庆祝反馈。
- [x] 夜间随机动作比白天更安静。
- [x] 随机行为间隔受控，不覆盖高优先级状态。
- [x] 减少动画模式稳定降级。
- [x] 互动奖励幂等，不形成点击刷分。
- [x] 内部任务可拖给宠物并执行完成、今天或专注。
- [x] 小房间、外观装扮、每日冒险、冒险奖励与四种小游戏。
- [x] 主动早晚问候、天气/同步/计划/休息建议和快捷回答。
- [x] 全屏、会议、专注、静音和安静时段免打扰。

## 11. 测试要求

1. 纯函数测试覆盖状态优先级、夜间动作、互动映射和时间边界。
2. Electron 端到端测试覆盖真实窗口拖动、右键互动、环形轮盘、协作小游戏、动作属性、回应气泡和亲密度增长。
3. 截图测试检查宠物无遮挡、气泡不被裁切、深浅色可读。
4. 全量回归任务、飞书、Agent、专注、悬停展开和窗口拖动。
5. 自动化 Electron 窗口以透明、非激活方式运行，不抢占用户当前工作焦点。
