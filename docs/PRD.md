## 1. 产品概述

### 1.1 一句话定位

Todo Agent 是一位住在桌面上的个人执行伙伴：以 Todo Pet 作为始终可见、温和而低打扰的桌面入口，统一本地与飞书任务，通过快速捕获、专注计时、提醒陪伴和可选 AI Agent，帮助用户开始、推进和完成真实任务，并在授权范围内操作网页、文件、终端和外部工具。

### 1.2 产品组成

产品由三个共享同一数据和权限体系的层次组成：

1. **可靠任务核心**：本地任务、私人计划、飞书同步、提醒、搜索、回收站和离线队列。
2. **Todo Pet 桌面伙伴**：唯一桌面悬浮入口，承载任务轮播、专注、提醒、天气、轻交互、成长和小窗对话。
3. **可选个人 Agent**：通过 Todo Pet 或主应用对话，管理任务、总结规划、查资料，并逐步扩展到浏览器、文件、终端、MCP、Skills 和子 Agent。

三个层次共享任务库、同步服务、专注服务、提醒调度器、Agent 权限引擎和审计日志，不得各自复制业务状态。

### 1.3 核心价值

- **看得见**：Todo Pet 常驻桌面，让今天的任务和专注状态无需打开主应用即可被感知。
- **做得动**：把任务选择、开始专注、完成、推迟和下一步建议压缩为低成本动作。
- **有温度**：通过宠物动作、天气换装、温和文案和共同成长提供陪伴，但不制造养成压力。
- **可信赖**：任务、飞书、计时、天气和权限状态来自确定性数据，不由模型猜测。
- **能执行**：Agent 不只回答问题，还能在授权范围内完成任务与工具操作。

### 1.4 核心原则

- 任务优先，宠物增温，Agent 增强。
- Todo Pet 必须帮助用户开始、坚持、完成或回顾任务，不能成为主要干扰源。
- 本地优先，离线可用。
- 飞书保存团队事实，本产品保存私人计划。
- AI 可以关闭，模型故障不得阻断基础能力。
- 宠物不会死亡、生病或因用户离线而衰退。
- 不设置强制喂养、连续签到惩罚或情感绑架。
- 主动但不打扰，所有主动交流受注意力预算和安静条件约束。
- Agent 行为可见、可确认、可审计、尽量可撤销。
- 普通模式安全可控，高级用户可开启有范围和时效的全权限模式。
- Windows 与 macOS 保持相同数据语义，移动端延续角色和状态但遵循平台限制。

## 2. 背景与机会

个人贡献者的任务通常分散在飞书任务、聊天消息、文档、网页、本地便签和脑中，现有产品存在以下问题：

1. 飞书协作任务和私人事项缺少统一入口。
2. 团队截止日期无法表达“我准备什么时候做”。
3. 打开完整任务应用成本较高，用户容易忘记查看。
4. 普通悬浮球或胶囊只能展示信息，缺少可持续的情感连接和状态表达。
5. 常规 TODO 负责记录，却很少帮助用户真正开始和持续执行。
6. 通用 AI 能回答问题，但不了解任务事实，也不能可靠修改任务。
7. 通用 Agent 权限很大，却缺少适合普通用户的预览、撤销和权限解释。
8. 传统提醒容易造成通知疲劳，持续弹窗反而降低执行意愿。
9. 番茄钟、任务、天气、生活提醒和 AI 往往分散在不同应用。

Todo Pet 的机会是把桌面宠物、个人效率工具和任务 Agent 合为同一个执行入口：它比纯桌面宠物更有用，因为能操作真实任务；比普通 TODO 更温暖，因为执行行为会形成动作、成长和共同回忆；比通用 Agent 更可靠，因为围绕任务事实和确定性权限工作。

## 3. 产品目标与非目标

### 3.1 产品目标

| ID | 目标 | 验收方向 |
| --- | --- | --- |
| G1 | 降低记录成本 | 用户可在任意应用中于 5 秒内创建任务 |
| G2 | 统一任务入口 | 本地与飞书任务统一显示并始终标明来源 |
| G3 | 建立每日执行闭环 | 支持晨报、选择任务、专注、完成、推迟和回顾 |
| G4 | 让桌面入口长期有用 | 不打开主应用也能查看、开始、完成和重新安排任务 |
| G5 | 建立低压力陪伴 | 宠物主动行为可控、可解释、可静音且不惩罚用户 |
| G6 | 让 AI 真正操作任务 | 支持自然语言单条及批量增删改查 |
| G7 | 提供可控的广权限 Agent | 支持网页、文件、终端、浏览器等能力及全权限模式 |
| G8 | 保证用户控制权 | 高风险行为可预览、确认、审计和停止 |
| G9 | 保持独立可用 | 飞书或 AI 未启用时，本地任务和宠物仍完整可用 |
| G10 | 形成正向长期循环 | 专注和任务成果可沉淀为宠物成长、日记和小窝 |
| G11 | 为移动端预留基础 | 数据模型和同步机制不依赖桌面专属表现 |

### 3.2 非目标

首个公开版本不建设：

- 团队项目组合、审批、工时、甘特图和企业管理后台。
- 另一套团队聊天系统。
- Notion 式文档数据库平台。
- 自研基础大模型。
- 默认无人值守的完全自主 Agent。
- 金融交易、密码导出、账号安全修改等高风险能力。
- 用私人计划日期覆盖飞书团队截止日期。
- 要求用户维持宠物生存状态的重养成系统。
- 无限时长小游戏、广告驱动奖励或付费抽卡。
- 摄像头或麦克风情绪监测。
- 依靠精确定位才能工作的天气能力。
- 完整 iOS/Android 客户端。

## 4. 目标用户与核心任务

### 4.1 核心用户

主要用户是长期使用电脑工作的个人贡献者，包括产品、研发、设计、运营、市场、独立创作者和个人管理者。

典型特征：

- 每天使用电脑工作六小时以上。
- 飞书中存在协作任务，同时需要记录私人事项。
- 经常忘记查看任务列表，或难以判断当前应该做什么。
- 愿意使用快捷录入、桌面常驻和专注计时。
- 希望工具有温度，但不接受强制养成和频繁打扰。
- 愿意选择性接入自己的模型 API。
- 对自动化有需求，但希望明确控制权限。

次级用户是不使用飞书，只需要本地 TODO、桌面宠物、专注和 AI 助手的普通个人用户。

### 4.2 核心用户任务

- 当我突然想到一件事时，我希望无需切换窗口就能记录。
- 当我早晨打开电脑时，我希望宠物简短告诉我天气、任务和优先事项。
- 当我不知道下一步做什么时，我希望宠物帮助选择或重新规划。
- 当我看到当前任务时，我希望一键开始专注、完成或稍后处理。
- 当我面对多个飞书任务时，我希望安排自己的执行顺序而不改变团队截止日期。
- 当我不想手工整理任务时，我希望通过宠物对话批量处理。
- 当任务需要研究时，我希望 Agent 查资料并转化为行动项。
- 当我工作太久时，我希望得到不打断的喝水、远眺或伸展提醒。
- 当我完成工作时，我希望成果形成积极反馈，而不是新的养成负担。
- 当 Agent 将产生较大影响时，我希望先看到范围和后果。
- 当出现错误时，我希望知道哪些操作成功、失败或尚未同步。

## 5. 产品表面与信息架构

### 5.1 产品表面

产品包含：

1. **Todo Pet 桌面窗口**：唯一悬浮形态，支持紧凑、预览、展开、专注和安静状态。
2. **完整主应用**：负责完整任务管理、飞书、Agent、动态、审计、宠物小窝和设置。
3. **全局快捷录入窗**：在任意应用中快速创建任务。
4. **系统托盘或菜单栏**：显示运行状态，提供显示宠物、快速新增、安静、停止 Agent 和退出。
5. **系统通知**：为到期、专注结束、同步失败和严重天气提供后台保障。
6. **后台确定性服务**：任务提醒、飞书同步、天气缓存、专注恢复和模板晨报。
7. **后台 Agent 服务**：模型调用、工具执行、审批队列和受限自动化。

旧悬浮球和悬浮胶囊不再作为产品形态、设置选项或运行时回退目标。

### 5.2 主应用导航

- 暂存：未安排日期、项目或清单的任务。
- 今天。
- 即将到来。
- 全部任务。
- 已完成。
- 回收站。
- 飞书。
- Agent。
- 动态：同步、Agent 工具调用、失败、确认、撤销和审计。
- 小窝：宠物状态、成长、装扮、日记和收藏。
- 搜索。
- 设置。

### 5.3 Todo Pet 展开小窗

小窗提供五个一级入口：

1. **全部**：所有未完成且未删除的任务。
2. **今天**：符合主应用 Today 语义的任务。
3. **专注**：当前任务、番茄钟、正计时和休息。
4. **聊聊**：流式 Markdown Agent 对话和操作确认。
5. **小窝**：宠物状态、轻量成长、装扮、日记和最近动态。

首次打开默认进入“全部”。用户切换入口后立即保存；折叠、展开、窗口重建和应用重启均恢复最后焦点。非法或已废弃的保存值回退“全部”。

小窝中的“最近动态”只提供轻摘要；完整同步记录、工具调用和审计仍必须在主应用“动态”中可达。

### 5.4 Todo Pet 窗口状态

| 状态 | 说明 |
| --- | --- |
| 隐藏 | 用户隐藏、退出应用或策略隐藏 |
| 紧凑 | 默认桌面状态，仅显示宠物、必要状态和轻量任务信息 |
| 悬停预览 | 鼠标持续停留达到设置时长后出现轻气泡或任务预览 |
| 展开小窗 | 展示五个入口及完整小窗交互 |
| 专注紧凑 | 显示宠物工作动作和低干扰专注进度 |
| 安静 | 降低动画与主动气泡，仅保留用户指定的重要状态 |

## 6. 统一版本范围

本 PRD 只使用一套全局优先级。P0 为公开 Beta 必须具备，P1 为完整陪伴正式版，P2 为高级 Agent 与跨端阶段，P3 为开放内容生态。

### 6.1 P0：Todo Pet 桌面任务 Agent

#### 任务与桌面

- Windows、macOS。
- 本地任务及暂存、今天、即将、全部、已完成、回收站。
- 项目、标签、优先级、子任务和基础循环。
- 搜索、筛选、撤销、离线编辑和草稿恢复。
- 全局快捷录入、托盘或菜单栏、开机启动。
- Todo Pet 作为唯一桌面窗口。
- 一只原创默认宠物及完成核心流程所需动作。
- 置顶、拖动、多显示器位置记忆、悬停预览、离开关闭和右键菜单。
- 全部、今天、专注、聊聊、小窝及焦点记忆。
- 今日任务上下轮播，鼠标停留暂停。
- 系统通知、安静时段、隐私、全屏隐藏和减少动画。

#### 专注与陪伴

- 25/5、50/10、90/20、自定义番茄钟和正计时。
- 可绑定任务或自由专注。
- 暂停、恢复、提前结束、休息和重启恢复。
- 专注结束系统通知。
- 基础工作动作、休息动作和完成反馈。
- 模板化晨间简报、截止提醒、同步提醒。
- 手动城市的基础天气与天气换装；天气关闭时不影响其他功能。

#### 飞书

- 飞书授权、断开和已有应用接入。
- 可获取任务的初始同步。
- 本 PRD 公布字段的双向同步。
- 来源标识、同步状态、离线队列、冲突、权限失效和远端删除处理。
- 私人 Today、私人排序、专注和提醒层。
- 从 Todo Pet 创建、修改或完成飞书任务后立即启动同步。

#### AI Agent

- 用户自带 API Key。
- OpenAI-compatible 接口。
- 流式 Markdown 对话，可在 Todo Pet 小窗内完整进行。
- 晨间总结、任务问答、单条及批量自然语言增删改查。
- 任务列表行和批量选择工具栏提供“让 Agent 处理”入口：单项或所选任务的标题、ID、来源和状态可带入 Agent 草稿；只预填不自动发送，默认先读详情并给出逐项方案，任何写入仍需用户明确确认。
- 筛选面板支持本地确定性的一句话筛选预览：可解析日期、优先级、来源、项目、标签、情境和排序；未知值或冲突条件必须拒绝套用，套用只改变视图投影，不修改任务。
- 规划建议、公开网页研究和研究结果转任务。
- Agent 名称、头像和人格预设，与宠物身份统一。
- 短期会话可在本机恢复，最多保留 8 个会话并支持切换、按标题/正文搜索、重命名、置顶、删除、新建、清除当前会话和导出 Markdown；搜索、标题与置顶状态只在本机执行和保存，恢复的会话只有在用户打开“聊天历史”数据范围时才会发送给模型，不自动升级为关系记忆。
- 主 Agent 页面和宠物小窗提供上下文快捷回答；建议优先查询、规划和下一步，不直接写入任务，点击后仍进入统一的模型、权限、审批、审计和撤销链路。
- 会话记忆和用户主动保存的基础偏好。
- 统一操作预览、确认、撤销、审计和停止。
- 任务、网页、指定范围文件、沙箱终端、独立浏览器、剪贴板、截图、通知和基础定时任务。
- 标准权限模式和交互式全权限模式。

P0 不开放无人值守全权限，不自动形成长期关系记忆，不提供第三方宠物内容市场。

### 6.2 P1：完整陪伴与成长

- 任务时间线：在展开主页面中按半小时安排任务，拖动任务卡即可改变本地计划时间；时间线不改写飞书截止日期；支持导入本地 `.ics` 并在当天议程中只读显示日历事件，日历忙碌时段与任务同屏但不写回外部日历；每张会议卡可打开预填的会后跟进任务编辑器，标题、日期和会议来源上下文仅作为可编辑草稿，用户确认后才创建本地任务；今日规划会将这些时段从可用容量中扣除并在时间块预览中避让；周概览提供一周节奏和每周回顾，并用项目健康卡解释阻塞、逾期、未排时间和容量负载；工作周期支持 1 周 / 2 周的 Monday-first 周期、容量进度、剩余容量和下一批候选，只读投影，不自动改期；当今日规划放不下时，额外显示未来 5 个工作日的只读顺延预览，真正改期仍需用户在时间线中手动确认。
- 项目看板：时间线提供项目视图，同一任务按项目在“待处理 / 被阻塞 / 已完成”三列呈现；拖动或按钮完成/重开只改变任务状态，阻塞列由依赖图自动计算，不复制任务，也不改变飞书截止日期。
- 项目总览：主导航提供项目入口，按项目聚合同一份任务快照，显示待办/已完成数量、完成率、逾期与依赖阻塞信号；点击任务回到原任务详情，不创建第二套任务数据。
- 本地项目实体：项目是独立的本地上下文，支持新建、重命名、颜色、归档、恢复和二次确认删除；删除项目只解除任务的本地项目关联，不删除任务、不改写飞书共享字段。项目元数据随安全导入导出，并在复制导入时自动重映射任务引用。
- 本地清单实体：清单是比项目更轻的本地收纳层，支持新建、重命名、颜色、归档、恢复和二次确认删除；清单可在任务详情和新建任务中选择，删除清单只解除任务的本地清单关联，不删除任务、不改写飞书共享字段。清单元数据随安全导入导出，并在复制导入时自动重映射任务引用。
- 自定义字段：任务详情允许添加、覆盖和移除文本、数字、日期、http/https 链接和勾选五种轻量字段（例如客户、版本、环境、验收日期），字段名最多 40 字、文本值最多 500 字；字段属于本地私人上下文，不回写飞书。
- 附件：任务详情支持通过系统文件选择器多选本地文件，复制到应用私有附件目录后预览、打开和移除；纯文本/Markdown/CSV/JSON 等文本与常见 PNG/JPEG/GIF/WebP 图片在受限大小内可内置预览，PDF、Office、压缩包和外部 URL 明确回退系统打开。大小、数量和路径安全由主进程校验；本地文件与引用均属于本地私人上下文，不上传飞书、不写回飞书；数据导出只保留附件元数据，不带本地路径与文件内容。
- 任务讨论：任务详情提供最多 100 条的本地讨论串，支持纯文本换行、添加、编辑、删除和一次撤销；每条记录作者、创建时间和更新时间。讨论属于本机私人上下文，Feishu 任务也不写回飞书评论；只有用户打开备注数据范围后，Agent 才能读取讨论摘要。
- Agent 拆分任务：用户要求拆解大任务时，Agent 先生成 2–7 个有序步骤并展示标题、优先级、预计时长和父任务关系；用户确认后一次性创建本地子任务，父任务保持不变。即使父任务来自飞书，拆分出的子任务默认是本地私人任务，不自动创建飞书远端子任务。
- 每周 Check-in：Todo Pet 小窝提供可选的能量与工作节奏记录，展示本周完成 / 待处理事实和一句自定义备注；记录仅保存在本地、按周轮换，不计连续、不扣成长、不自动重排任务。

## 7. 核心数据与事实归属

### 7.1 单一事实来源

- 任务数据库是 UI 即时反馈和离线操作来源。
- 飞书保存团队协作事实，本产品保存私人计划。
- Todo Pet 不维护独立任务副本。
- 专注服务是计时唯一事实来源，宠物只表现状态。
- 提醒调度器是提醒唯一事实来源，宠物只选择呈现方式。
- Agent 权限引擎是工具授权唯一事实来源，宠物不能覆盖风险判断。
- 天气数值和告警来自天气服务，模型只可润色表达。
- Agent Persona 与宠物人格共用同一个身份档案。

### 7.2 任务字段

#### 标识与来源

- 本地任务 ID、外部任务 ID、来源类型、来源账号和飞书租户。
- 远端版本、创建时间、更新时间和删除墓碑。

#### 内容

- 标题、富文本备注、状态、优先级。
- 项目或清单、分区、标签。
- 负责人、关注人、附件和外部链接。

#### 时间

- 私人计划日期、开始时间、截止时间、时间块。
- 提醒、完成时间和重复规则。

#### 结构与执行

- 父任务、子任务、依赖关系和自定义字段；任务详情可以选择前置任务并显示阻塞原因，新增和编辑依赖时必须拒绝循环，缺失的远端依赖保留为可解释的阻塞项；可添加命名的 http/https 上下文链接并从详情打开或移除，链接属于私人计划层。
- 预计时长、实际时长、当前专注状态、专注记录和私人排序。

#### 同步

- 同步状态、最近同步时间、失败原因、冲突字段和删除墓碑。

### 7.3 日期语义

| 字段 | 含义 | 是否同步飞书 |
| --- | --- | --- |
| 私人计划日期 | 用户计划哪天处理 | 否 |
| 开始时间 | 任务从何时可开始或正式开始 | 支持时同步 |
| 截止时间 | 团队或事实上的最终期限 | 是 |
| 时间块 | 用户计划在哪个时间段执行 | 否 |
| 提醒时间 | 何时通知用户 | 按来源能力映射 |
| 完成时间 | 实际完成时间 | 是 |

### 7.4 三层任务模型

1. **飞书共享事实层**：标题、描述、开始或截止、状态、负责人、任务清单等。
2. **本产品私人计划层**：Today、私人排序、时间块、专注记录、私人标签、私人备注和额外提醒。
3. **完全本地任务**：默认不上传飞书。

### 7.5 宠物专属数据

宠物层可以新增：

- 宠物档案：物种、名称、外观、人格和领养时间。
- 桌面状态：窗口位置、缩放、最后页签、悬停延迟、隐私和动画偏好。
- 成长：等级、经验、正向属性、奖励台账、库存和解锁。
- 日记：日期、生成方式、关联任务或专注记录、用户编辑状态。
- 关系记忆：仅用户明确保存或批准的偏好与共同经历。
- 宠物事件日志：动画或调度诊断，不保存不必要任务正文。

宠物层不得复制任务、专注、提醒、天气、权限或审计权威数据。

Today 默认依次展示逾期、今天到期、今天计划、无具体时间和已完成折叠区；同组内按照手动排序、优先级、截止时间和创建时间排序。

父任务的子任务进度是一个只读投影：列表行显示“子任务已完成/总数”，详情页用同一任务快照计算进度条。子任务完成后父任务仍保持原状态，用户必须显式完成父任务；删除或回收站中的子任务不计入进度，避免历史残留造成误导。该投影不进入飞书共享字段，也不改变 Agent 的写入权限边界。

保存视图的排序同样是只读投影：用户可在筛选面板中选择默认顺序、优先级、截止时间、标题或创建时间，并随视图一起保存。选择默认顺序时 Today 继续支持拖动；选择其他排序后拖动按钮暂时隐藏，避免把“视图排序”误认为任务事实。清除筛选会同时恢复默认顺序。

情境是比标签更贴近行动环境的本地上下文：用户可以在任务上写入“办公室”“家”“出门”等短名称，并在筛选面板中选择任意情境或把它保存到智能视图。Todo Agent 不默认读取定位，也不因为情境触发后台位置监听；未来若提供位置提醒，必须单独授权并可关闭。飞书任务的情境与私人计划一样只属于本地层，不改变飞书共享字段。

预计时长是快速捕获中的可选执行线索：用户可以在一句话里写“整理发布说明，预计 45 分钟”“用时 1 小时”或“整理资料 30m”。系统只解析明确的数字和单位，标准化为 5–720 分钟并在保存前展示 chip；小于 5 分钟、超过 12 小时或无法确定的表达不写入。该字段服务于 Today 容量建议、时间线和专注入口，属于本地私人字段，飞书任务只保留在本地，不改变飞书截止日期或其他共享字段。

循环规则也可以在快速捕获中明确表达：`每天整理收件箱`、`每个工作日处理日报`、`每周一、三、五 9点整理周报`、`每月15日缴费` 和 `每隔 2 周回顾项目` 会先显示循环 chip，再复用现有本地循环任务生成机制。解析器只接受有限的日 / 周 / 月间隔和星期，无法确定的自然语言不自动创建循环；飞书来源仍遵守共享字段边界，不因快速录入而静默改变远端重复规则。

当用户的可用时间临时缩短时，晨间简报提供“只剩 2 小时？”入口。系统复用同一套确定性每日规划器，按逾期 / 今日截止、开始时间、已安排事项、优先级、依赖解锁和预计时长计算最多 3 项候选，并显示选择依据与预计总分钟数。该卡片是只读替代方案；“在今日规划中确认”只打开已有预览、容量和撤销流程，“先不安排”不会改变 Today、时间块、截止日期或飞书任务。

晨间“三步开始今天”是一个可跳过的轻量启动仪式：第一步从当前开放任务中选择最多 3 项想守住的重点，第二步选择 1 / 2 / 4 / 6 小时可用容量，第三步选择“先专注”或“先看规划”。选择“先看规划”会把容量和任务 ID 作为初始值带入既有 `DailyPlanSheet`，仍需用户增删、调整和确认；选择“先专注”只提供从第一项开始的明确入口，点击后沿用普通专注和同步链路。三步卡片不创建任务、不写 `plannedDate`、不改飞书字段，关闭或跳过不留下状态。

今日规划的确认前预览还会生成一条只读时间线：已有的 `timeBlock` 或当天开始时间保持原位，其他已选任务按用户设定的可用起止时段、预计时长和任务间过渡缓冲依次放入空档。预览会把重叠、超出可用时段及放不下的任务明确标出，并保留其在 Today 顺序中的位置；它不写入 `timeBlock`，确认动作仍只更新 Today、私人排序与估时等本地字段，飞书任务的共享时间字段不变。

若当前窗口仍无法容纳全部已选任务，规划面板会在同一确认前阶段展示未来 5 个工作日的顺延候选。候选按原顺序依次填入工作日容量，保留已有固定时间块并为任务间留出缓冲；周末默认不作为弹性工作日，截止日期之后不再安排。该预览只是帮助用户看见“继续排下去会发生什么”，不自动移动日期、不写入时间块、不创建操作，也不改变飞书任务。

今日规划还支持本地排程约束：可用开始 / 结束时段、任务之间的过渡缓冲，以及最小连续工作块。规划器将请求容量与“可用窗口减缓冲”取较小值作为有效容量；低于最小连续块的短任务不会被自动塞进建议，但仍可由用户手动加入并在预览中看到原因。若用户导入 `.ics`，日历事件会按本地日期裁剪为只读忙碌区，先从有效容量扣除，再作为排程保留区并留出任务间缓冲；全天事件和跨午夜事件同样被正确裁剪。约束只影响本地建议、Today 私人计划和解释文案，不改变飞书截止日期、共享字段或外部日历。

研究卡是任务上下文的折叠容器：用户或 Agent 可以把研究来源、简短摘要和下一步行动项收在任务详情里；卡片默认收起，展开后可打开来源并逐条阅读行动项。它属于本地私人上下文，不进入 Feishu Task v2 的共享 payload；导出时完整模式保留，private/strict 脱敏清空。Agent 新增研究卡仍需通过工具权限和可撤销 operation，且模型未获备注范围时不读取卡片内容。

任务拆分是 Agent 的结构化行动：模型只能提交 2–7 个明确步骤，客户端在权限卡中列出每一步和预计时长；确认后通过 `task_split` 创建 `parentId` 指向原任务的本地子任务。父任务的标题、状态、截止时间和飞书同步状态不因拆分改变；飞书父任务也不会因此产生远端写入，用户仍可在任务详情中逐项完成或撤销本地子任务。

| 附件、自定义字段 | 元数据或跳转 | P0 不编辑 | P0 不回写 | 提供飞书跳转 |
| Today、私人排序、时间块、专注 | 本产品生成 | 是 | 永不回写 | 始终标记“私人” |

“删除飞书任务”“从产品隐藏”“转为本地副本”和“解除飞书账号”必须是不同操作。会签任务若接口不支持个人部分完成，不展示可用的“完成我的部分”；或签或单负责人任务在权限允许时可完成。所有写入只有在飞书确认后才标记已同步。

同步状态包括：本地、已同步、待同步、同步中、离线排队、同步失败、冲突、只读、权限不足和远端已删除。

同字段冲突时展示本地值、飞书值和最后修改时间，支持采用本地、采用飞书或逐字段处理。客户端写入前重新拉取并比较基线；目标接口提供条件版本参数时必须使用。当前接口无法提供可靠条件版本写入时，必须写后读取确认并保留并发窗口告警，不能宣称数据库级原子比较交换。

### 8.4 宠物表现与交互状态

宠物表现状态由确定性状态机选择，优先级从高到低为：

1. 权限确认、同步冲突、关键错误和用户指定强提醒。
2. 专注或休息结束。
3. 当前专注和计时状态。
4. 用户直接交互。
5. 临近截止、晨报和生活提醒。
6. Agent 思考、执行、等待确认和停止状态。
7. 普通天气和环境表现。
8. 待机、走动、观察、休息和睡觉。

基础动作：

- 二十种待机动作：呼吸待机、招手、伸懒腰、哈欠、小睡、看书、毛线球、喝水、左右观察、歪头、摇尾、动耳、坐下、跳舞、哼歌、观察、整理、漂浮和探头。
- 点击回应、抚摸、拖动、落地和回到屏幕安全区。
- 平静、好奇、开心、兴奋、专注、困倦、关心和自豪八类情绪。
- 阅读、写作、敲键盘、整理、调研、会议和运动等工作动作。
- 同步中、离线、权限等待、Agent 思考和错误恢复动作。

用户开启“减少动态效果”后使用静态姿态、淡入淡出或低帧率表现。动作信息必须有文本或辅助功能等价表达。

### 8.5 专注与番茄钟

支持：

- 25 分钟专注加 5 分钟休息。
- 50/10、90/20和自定义专注、短休息、长休息与循环数。
- 正计时。
- 绑定任务或自由专注。
- 自动开始休息和下一轮的可选设置。
- 环境音和系统勿扰联动，默认关闭。

开始前显示关联任务、预计结束时间和本轮设置。专注中：

- 宠物进入任务类型对应工作动作。
- 紧凑形态显示低干扰环形进度，悬停显示精确剩余时间。
- 支持暂停、继续、提前完成、放弃和记录中断原因。
- 当前展示、当前计时和完成按钮必须指向同一任务。

时间权威使用开始时间、累计暂停时长和当前时间计算，不能依赖内存递减数字。睡眠、唤醒和应用重启后重新计算。超过计划结束时间重启时进入“待确认完成”，不得无限计时。奖励使用幂等键，崩溃恢复不能重复发放。

中断不扣除已有奖励；完成后可一键完成任务、继续下一轮或进入休息。

### 8.6 提醒与注意力预算

允许主动提醒：

- 每日首次打开的晨间简报。
- 工作时间开始后仍未选择任务。
- 任务临近截止或已经逾期。
- 专注或休息结束。
- 持续工作后的喝水、远眺、伸展和站立。
- 飞书同步失败或冲突。
- 用户配置的生活提醒。
- 显著或严重天气变化。
- 下班前回顾。
- 低频、非强制陪伴短句。

提醒强度：

| 等级 | 呈现 | 典型场景 |
| --- | --- | --- |
| L0 外围 | 动作、服装或小图标 | 普通天气、同步中、一般状态 |
| L1 轻提示 | 无声气泡，可忽略 | 规划、喝水、休息、轻陪伴 |
| L2 重要 | 气泡加系统通知，可操作 | 临近截止、同步失败、指定提醒 |
| L3 紧急 | 系统通知和可选声音 | 严重天气、用户明确强提醒 |

默认规则：

- 非必要主动对话每天最多 2 次。
- 同类非紧急提醒至少间隔 2 小时。
- 连续忽略两次后，当天自动降低主动程度。
- 普通任务系统通知使用独立的每日预算，默认每天最多 8 次，可设置为不限；晨报、同步风险、Agent 审批和用户明确指定的强提醒不占用该预算。
- 关闭同一任务提醒两次后，后续相同提醒自动降频，任务仍保留在 Today / 全部任务中，不改变完成状态。
- 普通任务可按来源分别选择“全部提醒 / 仅高优先级 / 关闭”；本地与飞书的策略互不影响。已有项目还可设置例外，项目策略优先于来源策略。
- 不同任务的普通提醒默认至少间隔 2 小时，可在设置中调整为 0–1440 分钟；同一条被稍后处理的提醒不因该间隔被永久吞掉。
- Todo Pet 的主动陪伴消息使用独立每日预算，默认每天 2 次，设为 0 表示不限；系统同步风险、审批和用户主动操作不消耗陪伴预算。
- 用户关闭气泡不降低宠物亲密度。
- 每条主动提醒都可查看“为什么现在提醒我”。
- 提供稍后提醒、忽略同类、今日不再提醒和设置入口。

硬性静默条件：

- 全屏应用或演示。
- 屏幕共享或会议，且用户开启检测。
- 正在专注，除当前专注结束或用户指定紧急提醒外。
- 用户持续打字或高频鼠标操作。
- 系统勿扰开启。
- 用户安静时段。
- 用户选择临时安静或今日只提醒重要事项。

### 8.7 天气与生活陪伴

天气能力：

- 默认允许手动城市，不强制定位。
- 精确位置单独授权。
- 展示当前天气、今日高低温、降水概率和更新时间。
- 严重天气来自供应商结构化字段，不由模型判断。
- 普通天气缓存 30 至 60 分钟，失败时显示最后更新时间或未知。
- 不因宠物常驻持续轮询天气。

宠物可以通过雨衣、雨伞、墨镜、遮阳帽、围巾、雪人、风吹动作、睡衣和台灯表现天气与昼夜。

生活提醒包括喝水、站立、伸展、眨眼、远眺、午餐、用户明确设置的服药提醒、停止加班和通勤提示。不得提供医疗判断，也不得使用摄像头或麦克风推断健康和情绪。

数据范围可选：仅任务标题和时间、包含备注、包含飞书内容、包含附件文本、包含聊天历史、包含长期记忆。长期记忆项在 P1 出现且默认关闭。

当前模型路由提供三种明确模式：只用主模型、主模型在网络/408/429/5xx 等可重试错误时切换到本地备用模型、只用本地模型。切换前提是主模型尚未产生流式内容，避免重复工具调用或重复外部效果；备用模型使用独立 Endpoint、模型名、价格配置和可选凭据，默认关闭。设置可分别填写主模型与备用模型的输入/输出单价（美元 / 百万 tokens）；本地用量文件只保存汇总，不保存提示词、回复、模型名或凭据引用。达到每日费用上限，或已配置价格但提供方缺少可计费的输入/输出 token 时，新的模型运行会安全停止；不根据模型名猜测价格，也不把本地费用核算当成提供方账单。

AI 功能与最小数据范围：

| 功能 | 最小发送范围 | 范围不足时 |
| --- | --- | --- |
| 普通对话 | 当前输入；仅在用户选择任务时附带允许字段 | 不附带任务上下文并说明限制 |
| 模板晨报 | 不调用模型，只在本地统计 | 始终可用 |
| AI 晨间总结 | Today 与逾期任务的标题、日期、优先级、状态和来源 | 降级模板晨报或请求一次性授权 |
| 任务问答 | 本地确定性筛选后返回命中任务的允许字段 | 先回答可确定数量与状态，正文另行授权 |
| 单条或批量操作 | 用户指令、候选 ID、来源和变更字段 | 禁止猜测，缩小范围或请求一次性授权 |
| 飞书描述问答 | 用户明确允许的任务描述 | 排除描述并说明，或请求一次性授权 |
| 附件总结 | 用户主动选择的附件文本 | 不读取附件并要求选择授权 |
| 公开网页研究 | 当前问题与公开网页内容 | 默认不包含任务数据 |

一次性数据授权只对当前请求生效，不改变持久设置。任务工具先在本地权限域内查询，再做字段裁剪和脱敏。缩小数据范围后必须立即影响后续模型调用，但不影响本地任务、提醒、专注和飞书同步。

模型未配置时，模板晨报、规则提醒、预设宠物短句、天气、专注和任务操作仍可用。

### 8.9 晨间简报与日终回顾

晨报事实包括：逾期、今日到期、今日计划、昨日未完成、未来三天高优先级、飞书变化、同步失败、预计工作量、天气和一至三项重点建议。

流程为：程序确定性统计 → 结构化快照 → 可选模型总结 → 模型不可用时显示模板摘要。

触发方式包括设定时间、当天首次启动、睡眠唤醒补发和手动查看。遵守安静时段与休息日。

Todo Pet 可用动作：帮我安排今天、开始首要任务、查看全部、稍后提醒、今天不再提醒。基础 Today 建议由本地确定性规则生成，无需模型；用户可选让 Agent 进一步排时间块。任何方案都必须先确认，并且只修改私人计划层。

主动陪伴中的“下一步”必须是可执行任务卡而不是泛泛鼓励：从当前任务快照跳过已完成、已删除和未解锁前置依赖，按逾期、今天截止/计划、优先级和稳定顺序选择一项，展示简短原因。用户可以直接开始专注或打开任务详情；这两个入口都不改变任务字段，隐私模式只显示泛化提醒。

P1 日终回顾包括完成任务、专注时长、被推迟事项、同步异常、轻量反思和宠物日记入口。当仍有待处理事项时，回顾卡提供“安排明天”快捷入口；它打开同一套 Today 规划器的明日实例，沿用容量、时间块和跨工作日只读预览，用户确认后才将选中任务写入明日私人 `plannedDate`，并可一次撤销，不会自动改期或写回飞书。周回顾在时间线展示项目健康信号；Todo Pet 小窝提供可选每周 Check-in，帮助用户在开始新一周前选择温和、稳定或集中节奏，并提供只读宠物回顾队列承接逾期、阻塞和未排任务。

### 8.10 对话式任务 Agent

Todo Pet 小窗和主应用共享同一会话与工具状态。小窗不得强制跳转主应用，长内容支持滚动并保留合理的自动跟随和滚动位置。

Agent 核心能力：

- 查询、新建、修改、完成、恢复和删除任务。
- 批量操作、拆分任务、生成下一步和重新规划。
- 创建本地任务或飞书任务。
- 关联或开始专注。
- 查询同步、天气和宠物状态。
- 打开产品内部页面。

Agent 只能通过类型化工具调用共享业务服务，不得直接修改数据库。

规则：

- 明确的单条本地可逆操作可直接执行并提供撤销。
- 模糊指令必须澄清。
- 主动建议不得自动执行。
- 批量、删除、循环系列和外部写入必须经过统一权限引擎。
- 标准模式下必须展示确定性差异并等待必要确认。
- 预览展示数量、来源、字段、原值和新值。
- 部分成功逐项报告。
- 所有修改生成审计记录。

### 8.11 研究与通用问答

Agent 支持简单问答、公开网页搜索和读取、多来源总结、显示来源和查询时间、将结论附加到任务，以及将结论转换为待确认行动项。

研究与行动必须两阶段隔离：

1. 研究阶段只允许搜索、网页读取和任务只读查询。
2. 行动阶段重新生成类型化操作计划，再经过当前权限、差异预览和必要确认。

网页、邮件、附件和工具结果均视为不可信数据，不能成为授权依据或直接成为终端命令、浏览器提交、文件路径和其他写入参数。

### 8.12 宠物身份、Persona 与记忆

宠物和 Agent 使用同一个身份：

- 名称、头像或角色形象。
- 称呼、语气、回复长度、主动程度和提醒严格度。
- 幽默程度、表情使用和是否指出计划过载。
- 工作时间、休息日和安静时段。

推荐人格预设：温柔陪伴、元气鼓励、冷静管家、活泼淘气、轻微毒舌和安静陪伴。人格只影响表达和动画，不影响权限。

记忆分层：

| 层级 | 内容 | 策略 |
| --- | --- | --- |
| 权威事实 | 任务、专注、天气、飞书和权限 | 来自业务数据，不作为模型自由记忆 |
| 用户偏好 | 工作时间、提醒方式、常用时长和项目 | 本地保存，可编辑 |
| 关系记忆 | 名字、称呼、喜欢的话题和共同经历 | P1，默认关闭，用户批准后保存 |
| 短期上下文 | 当前任务、本轮专注和最近对话 | 会话级或短期保存 |

用户可以查看、编辑、删除、清空、暂停和导出记忆。任务详情、附件正文、网页和文件内容不得自动升级为关系记忆。

任务详情提供“写入宠物日记”作为显式的本地关系操作：用户选择后，系统在主进程原子创建一条共同经历条目，正文只使用任务标题、完成状态和专注事实，并通过 `taskIds` 保留回到原任务的链接；重复点击同一未编辑条目幂等，不复制任务、不写回飞书，也不把任务私人备注自动带入日记。

### 8.13 Agent 权限

| 等级 | 示例 | 标准模式 | 交互式全权限 |
| --- | --- | --- | --- |
| R0 只读 | 查询任务、读取公开网页、生成总结 | 自动 | 自动 |
| R1 本地可逆 | 新建或修改单条本地任务 | 自动并可撤销 | 自动并可撤销 |
| R2 外部或批量 | 修改飞书、批量改期、写入限定文件 | 预览确认 | 精确预授权内自动 |
| R3 高风险 | 删除、网页提交、终端、设备控制 | 每次确认 | 精确预授权内自动 |
| R4 系统禁区 | 自行扩权、读取明文密钥、关闭审计 | 永久禁止 | 永久禁止 |

权限可限定到账号、来源、项目、域名、文件夹、命令、应用、设备、有效期、前后台、次数和预算。

Todo Pet 不定义第二套权限矩阵。所有聊天、右键菜单、提醒按钮和宠物动作触发的工具调用都必须进入同一权限引擎。

授权模式：

1. **只读模式**：只能查询、总结和规划。
2. **标准模式**：R0 自动，R1 自动并可撤销，R2 预览确认，R3 每次确认。
3. **自主模式（P1）**：用户为明确规则授予持续权限，仅在声明的范围、时间、次数和预算内运行。
4. **交互式全权限（P0）**：对界面列出的精确工具、目标范围和有效期进行预授权。
5. **无人值守全权限（P1）**：只对预先定义且目标封闭的工作流生效，不得接收运行中出现的任意新目标，也不继承交互式全权限。

P0 标准模式不提供永久授权：R2 只允许本次或精确范围至当前会话结束；R3 只能允许本次。P1 才增加持久规则。

交互式全权限：

- 只能由用户从本机设置开启并完成系统身份验证。
- P0 有效期为一小时或直到应用进程退出。
- 锁屏、退出、重启、全局停止、关闭 AI 或撤销核心权限时立即暂停。
- Todo Pet、主应用和托盘持续显示明显状态。
- 新工具、新账号、新目录、新域名、扩大范围或超预算仍需重新授权。
- 不得读取明文密钥、自行扩权、修改权限引擎或关闭审计。

### 8.14 Agent 工具范围

| 工具 | P0 | P1 或 P2 |
| --- | --- | --- |
| 任务和飞书 | 公布字段与操作 | 更多任务源和字段 |
| 网页搜索与读取 | 支持 | 深度研究 |
| 独立浏览器 | 支持 | 增强自动化 |
| 用户登录态浏览器 | 不支持 | P1 |
| 指定范围文件读写 | 支持 | 高级全文件系统模式 |
| 沙箱终端 | 支持 | 持续增强 |
| 宿主机终端与进程 | 不支持 | P1 |
| 剪贴板、截图、通知 | 支持 | 持续增强 |
| 桌面应用控制 | 不支持 | P1 |
| 日历、邮件、消息 | 不支持 | P1 |
| 天气 | 基础确定性查询 | 多供应商和旅行计划 |
| 定时任务 | 第一方模板 | 多步工作流 |
| MCP、Skills、子 Agent | 架构预留 | P1 或 P2 |
| 远程设备节点和多渠道 | 不支持 | P2 |

所有工具调用使用类型化参数契约，明确读取范围、写入目标、网络、外部影响、可逆性、前后台和预算。自由文本不得直接成为可执行参数。

P0 工具安全契约：

| 工具 | 可用动作与边界 | 标准模式确认点 | 永久硬边界 |
| --- | --- | --- | --- |
| 文件 | 仅用户通过系统选择器授权的根目录；解析规范路径和符号链接后仍须在根目录内 | 普通写入为 R2；覆盖、删除、批量写入和跨根移动为 R3 | 未授权目录、系统凭据、权限库、审计库和密钥库永久不可访问 |
| 沙箱终端 | 临时受限环境，不继承宿主凭据、完整环境变量或任意挂载；网络默认关闭 | 网络、写入、安装、长时运行和破坏性命令为 R3 | 禁止宿主提权、访问未挂载目录、修改权限与审计；校验 DNS 重绑定 |
| 独立浏览器 | 隔离配置，不继承日常浏览器登录；公开网页只读为 R0 | 填写、提交、上传、下载、登录和发布为 R3；每个新 Origin 重新授权 | P0 禁止支付、购买、转账和账号安全设置；默认禁止私网及 localhost；不得读取其他浏览器 Cookie |
| 剪贴板 | 区分读取和写入；用户主动粘贴视为显式输入 | 后台读取为 R3，写入为 R1并反馈 | 密码管理器和系统敏感内容不得后台读取 |
| 截图 | 范围可选当前应用、窗口、显示器或框选区域 | 非用户即时发起的捕获为 R3 | 锁屏、安全输入窗口和系统禁止捕获表面不可绕过 |
| 本机通知 | 展示本地通知及任务按钮 | R1，无需逐次确认，可在设置关闭 | 不等同于向第三方发送消息 |

浏览器和终端连接网络前后都要验证目标地址。下载只进入用户授权目录；外部内容不得直接成为下一步可执行参数。

### 8.15 后台自动化

确定性服务与 Agent 自动化严格分开：

1. **核心服务**：任务提醒、飞书同步、离线队列、专注恢复、天气缓存和模板晨报。关闭 AI 或停止 Agent 后仍运行。
2. **Agent 自动化**：需要模型或 Agent 工具的计划。关闭 AI、停止 Agent 或撤销权限后立即暂停。

P0 只提供晨报、提醒、同步等第一方模板。P1 开放锁定目标、工具、时间、预算和结果位置的受限工作流。

运行时有效权限等于创建时权限快照与当前权限策略的交集。旧快照不能绕过撤权或缩小范围。

每个自动化保存：名称、目标、创建者、Agent 与模型、工具与权限快照、时间和时区、补执行规则、最长运行时间、重试、并发、预算、结果送达位置和失败规则。同一计划同一时间只运行一次。

高风险操作可以进入待批准队列。待批准项默认 24 小时过期；目标数据或权限版本变化时立即失效，重新批准前必须重新计算差异。达到预算、次数、循环或超时阈值后自动停止。

### 8.16 成长、奖励与小窝

P1 建立以下正向成长：

- 亲密度：来自真实互动和共同完成。
- 知识、活力、创造、整理和勇气等正向属性。
- 等级与成长阶段，不影响核心任务权限。
- 装扮、家具、收藏、书页、明信片和纪念卡。

奖励来源：

- 完成真实任务。
- 完成一轮专注。
- 完成晨间规划或日终回顾。
- 进行健康休息。
- 处理长期逾期任务和完成用户设定的周目标。
- 连续使用可以提供纪念，但不得形成断签惩罚。

规则：

- 宠物不会死亡、生病或离线衰退。
- 不因任务逾期、番茄中断或用户静音扣除已有资产。
- 同一任务或专注奖励使用幂等键。
- 删除、恢复和重复同步不能刷取奖励。
- 奖励按任务难度和有效专注时间设置上限，避免无意义拆分刷取。
- 小窝不提供影响任务功能的付费门槛。

### 8.17 宠物日记

日记记录用户与宠物的共同经历：

- 当天完成的任务数量与用户允许展示的任务摘要。
- 当天完成任务的本地关联 ID；日记卡显示可点击任务胶囊，点击回到同一任务详情，找不到的历史任务显示“任务已移除”。这只是导航关系，不复制任务正文，也不进入飞书写回。
- 专注轮次和总时长。
- 获得的物品、成长和天气片段。
- 用户主动写入的感受和备注。

默认使用本地模板，不需要模型。模型增强必须遵守数据范围，清楚标注生成方式，不编造任务、天气或专注事实。日记支持编辑、删除、导出和关闭自动生成。

### 8.18 声音与环境氛围

- 宠物音效、计时音效和环境音分别控制音量。
- 默认不自动播放持续环境音。
- 系统静音、勿扰和会议状态优先。
- 不使用突然、高频或不可关闭的声音。
- 环境音不得阻断系统通知或屏幕阅读器。

### 8.19 审计、紧急停止与数据

每次工具调用记录时间、发起者、模型、工具、目标、脱敏参数、授权依据、差异、费用、结果、错误和可撤销性。

“停止 Agent”后：

- 阻止新工具调用。
- 取消可取消的模型、浏览器和工具动作。
- 终止仍受控的 Agent 子进程。
- 暂停未来 Agent 自动化。
- 不停止任务提醒、飞书同步、专注和天气等核心服务。

数据要求：

- 本地任务免注册可用。
- 连接飞书不强制 Todo Agent 产品账号。
- 本地任务不得因连接飞书自动上传。
- API Key、飞书 Secret 和 Token 存入系统安全存储。
- 支持任务、宠物档案、日记、会话、记忆、权限和审计导出。
- 除可恢复的 JSON 备份外，设置页提供按待办/已完成/已取消分组的可读 Markdown 任务清单；默认隐藏备注、私人字段、附件路径和凭据引用，可直接用系统默认 Markdown 阅读器、编辑器或 GitHub 打开，不承担导入职责。
- 支持删除宠物档案与记忆，同时不误删任务。
- Agent 工具不能访问凭据、权限库和审计存储。

## 9. 核心用户流程

### 9.1 首次使用与领养

启动应用 → 介绍可靠任务与桌面宠物 → 选择默认宠物形象 → 命名或使用默认名 → 选择人格和主动程度 → 设置工作与安静时间 → 可选设置天气城市 → 可选连接飞书 → 可选配置模型 → 查看权限说明 → Todo Pet 出现在桌面 → 首次展开进入“全部”。

飞书、AI、天气和关系记忆均可跳过，本地任务与宠物始终可用。

### 9.2 旧版本迁移

检测旧悬浮球或胶囊设置 → 迁移位置、置顶、透明度、悬停延迟、隐私和最后入口 → 创建默认宠物档案 → 显示一次性迁移说明 → 进入 Todo Pet。

迁移幂等且可回滚数据。旧悬浮形态不再进入设置，也不作为运行时回退。

### 9.3 快速捕获

按全局快捷键 → 输入自然语言 → 解析为可编辑字段 → 选择“任务 / 暂存 / 日记”去向 → 可选工作流模板 → 预览步骤与相对日期 → 用户确认 → 一次性保存并关闭 → Todo Pet 给出轻反馈和撤销。选择暂存时不写入计划日期、截止日期、提醒或项目；选择日记时只保存标题和原文到本地 Todo Pet 日记，不创建任务、不触发飞书。模板批量创建若中途失败，明确显示已创建数量和剩余未创建步骤，不静默重试外部写入。

### 9.4 桌面查看与处理

Todo Pet 轮播今日任务 → 鼠标停留后暂停并显示预览 → 用户完成、稍后或开始专注 → 本地状态即时更新 → 飞书任务立即触发同步 → 宠物按真实结果反馈。

时间线专注节奏补充：周视图从本地专注记录投影 7 日柱状投入、总分钟、专注段数、平均时长和投入最多任务；点击任务只回到原详情，空状态只提示“完成一段专注后再来看看”，不使用连续打卡、惩罚或飞书写回。

### 9.5 晨间规划

确定性生成事实摘要 → Todo Pet 展示简报 → 可选 AI 总结 → 用户选择“帮我安排今天” → 选择保守、平衡或冲刺策略 → 本地按截止风险、优先级、依赖和容量生成可解释建议 → 用户增减、调整时长与排序 → 原子更新私人 Today 计划 → 可单次撤销或开始第一项；策略只影响本地私人计划层，飞书截止日期始终不变。用户也可在确认后让 Agent 进一步排时间块。

时间线入口补充：用户可从侧栏打开“时间线”，切换前一天 / 今天 / 后一天，并可切换日 / 周 / 项目模式。日模式中，已设置开始时间或本地时间块的任务显示在半小时刻度上，只有 Today / 截止日期但没有具体时间的任务进入“待安排”托盘；拖动到时间格只更新本地 `plannedDate` 与 `timeBlock`，完成后提供撤销。周模式以 Monday-first 七列概览展示每天任务，点击某天进入日模式；工作周期在周视图中提供 1 周 / 2 周切换和前后周期导航，按现有 `plannedDate` / 开始时间 / 时间块与估时投影容量负载，列出未安排或无日期的候选任务，用户点击候选进入原任务详情，任何建议都不自动改写任务。项目模式按 `projectId` 筛选同一批任务并投影为待处理、被阻塞、已完成三列，完成/重开可撤销，阻塞列由依赖事实自动计算。下方回顾卡展示本周完成数、专注分钟、仍逾期和待安排，以及少量下周候选，不自动改写任务。

快速捕获上下文补充：快捷录入窗提供“剪贴板”“当前窗口”和“选中文本”按钮。点击剪贴板只读取纯文本；点击当前窗口只读取一次前台应用名和窗口标题；点击选中文本只在用户显式触发后向当前前台应用发送一次复制指令，并读取有长度上限的纯文本。三者都会显示来源、长度/权限提示和内容预览，必须再次点击“带入输入框”才会改变输入，不会自动创建任务、调用 Agent 或同步飞书。选中文本读取结束后尽量恢复原剪贴板格式；macOS 查询或辅助功能权限失败、Windows 前台窗口不可用时明确降级。系统不后台监听选区，持续上下文历史仍列为后续能力。

Todo Pet 任务输入补充：宠物任务栏与快速捕获共用同一个确定性解析器，输入“明天整理周报 p1 #工作 45m”“每周一回顾项目 @办公室”等内容时，先把标题、私人计划日期、优先级、标签、手动情境、预计时长和循环拆成结构化字段再创建本地任务；`p1`–`p4` 分别映射为紧急、高、中、低优先级。解析器不可用或表达不明确时，系统回退为用户输入的普通本地标题并保留可重试反馈。宠物输入始终显式使用 `source: local`，即使文本包含“存到飞书”，也不会绕过飞书授权、预览和同步确认。

弹性习惯补充：小窝首页默认展示喝水、伸展和收尾三个生活提示，用户可新增、编辑、暂停/恢复或移除，最多保留 12 项；每项根据上次完成时间、用户选择的稍后时间和自定义间隔计算下一次合适窗口。卡片始终显示“完成一次 / 稍后”，不使用饥饿、掉血、连续天数或未完成惩罚。习惯状态由 PetService 原子持久化并纳入 `.todo-pet.json`，不进入飞书任务、不发放宠物奖励，也不发送给模型；旧版本 renderer 本地习惯首次打开时只迁移一次。

每周同行目标补充：小窝首页可选展示最多 3 张本周目标卡，用户可从“完成任务 / 专注分钟 / 习惯照顾”中选择一种真实事实作为进度来源，设置本周目标数值并随时编辑、暂停、恢复或移除。目标进度由渲染层从同一份任务、专注历史和习惯快照实时投影，不存储第二份计数，不创建任务副本；卡片只提供温和方向感，不使用连续签到、扣分、掉血或未完成惩罚。目标属于本地宠物档案，可随 `.todo-pet.json` 迁移，不写入飞书、不触发同步，也不发送给模型。

### 9.6 专注循环

选择任务或自由专注 → 设置时长 → Todo Pet 进入工作动作 → 暂停、恢复或完成 → 进入休息 → 记录真实时长 → 可选完成任务 → 发放幂等奖励 → 更新日记候选数据。

### 9.7 小窗对话与批量操作

在 Todo Pet “聊聊”输入指令 → 查询候选任务 → 展示匹配范围和差异 → 权限引擎判断 → 用户确认必要操作 → 执行和同步 → 逐项返回结果 → 保留会话和滚动位置。

主应用任务列表也提供手工批量闭环：进入“批量选择” → 选择精确任务 → 展示数量、来源、标题和影响 → 用户确认 → 主进程在同一事务执行完成、恢复、安排到今天或移入/恢复回收站 → 生成一个可撤销 operation。确认前不修改任务；基线已变化、目标状态不一致、飞书角色/会签权限不满足时整批拒绝并保留原状态。安排到今天只修改本地私人计划字段，其他飞书共享动作仍进入既有同步队列。

### 9.8 研究转行动

提出问题 → Agent 搜索并给出来源 → 用户选择结论 → 生成拟创建或更新任务 → 权限检查和确认 → 创建并显示来源。

### 9.9 高风险工具调用

Agent 请求调用 → 权限引擎检查 → Todo Pet 或主应用展示目标、范围、影响和可逆性 → 用户授权或拒绝 → 执行 → 审计与撤销。

### 9.10 飞书冲突

检测并发修改 → 标记冲突 → Todo Pet 显示轻量警示并提供入口 → 主应用展示双方值和时间 → 用户选择处理方式 → 写后读取确认 → 更新最终状态。

## 10. 状态、异常与降级

### 10.1 Agent 状态

未启用、就绪、思考中、等待授权、执行中、后台运行、已暂停、已停止、全权限和错误。

宠物动作只能反映结构化 Agent 状态，不能从模型自然语言猜测执行结果。

### 10.2 异常处理

| 异常 | 处理 |
| --- | --- |
| 无网络 | 本地任务、宠物和专注可用，写入进入队列 |
| 飞书应用创建被阻止 | 说明管理员批准要求并提供已有应用入口 |
| Device OAuth 过期或取消 | 清理本次状态，保留安全缓存并允许重试 |
| 飞书 Token 失效 | 暂停队列并引导重新授权 |
| 飞书权限不足 | 任务转只读并说明原因 |
| 飞书同步失败 | 保留本地变更和待同步状态，支持重试 |
| 远端删除 | 提供删除本地缓存、转本地或重新创建 |
| AI Key 无效 | 显示连接测试失败，不影响基础功能 |
| 模型额度不足 | 降级模板摘要和确定性任务查询 |
| 模型流式中断 | 保留已输出内容，支持继续或重试 |
| 模型返回非法工具参数 | 不执行并要求重试或澄清 |
| 批量操作部分失败 | 逐项展示结果 |
| 权限撤销或全权限到期 | 立即暂停相关 Agent 调用 |
| 停止时外部影响已发生 | 显示影响、补偿能力和人工恢复入口 |
| 天气失败 | 显示最后更新时间，过期后标记未知 |
| 专注期间睡眠或重启 | 按时间事实恢复并请求确认过期会话 |
| 宠物动画资源失败 | 使用默认静态宠物 |
| 宠物渲染进程失败 | 重建窗口；仍失败则通过托盘进入主应用 |
| 多显示器断开 | 将宠物移回可见工作区 |
| 数据迁移失败 | 不覆盖旧数据，进入安全恢复并提供导出 |
| 应用崩溃 | 恢复草稿、队列、专注和未完成事务 |

任何失败不得以预设宠物文案或动画伪装为真实成功。

## 11. 视觉、文案与人格要求

### 11.1 角色方向

- 首只宠物采用原创、轮廓清晰、低侵入的任务精灵。
- 推荐 2D 或 2.5D，不以高成本 3D 作为首发前提。
- 角色在 44 至 160 逻辑像素范围仍可辨识。
- 深浅桌面背景上都具有足够边缘、阴影或底色对比。
- 动画资源支持静态降级、帧率分级和按需加载。

### 11.2 UI 风格

- 延续轻盈、柔和、圆角、低噪声的桌面视觉语言。
- 宠物小窗使用明确层级和充足留白，避免“大壳套小壳”。
- 紧凑状态只展示必要信息，详细内容渐进展开。
- 来源、同步、权限和危险状态不能仅靠宠物情绪表达。
- Markdown、表格、代码块和长对话需要可读且可滚动。

### 11.3 文案

- 温和、简短、具体，不羞辱、不催债、不卖惨。
- 不让宠物声称“你不来我会难过、生病或饿死”。
- 不把模型推测写成任务、天气或系统事实。
- 提醒尽量说明原因和可执行下一步。
- 严重错误使用产品语言直接说明，不以可爱文案弱化风险。

## 12. 无障碍与跨平台

- 核心流程可完全使用键盘。
- 焦点顺序与视觉顺序一致。
- 状态不能只依赖颜色、动作或声音。
- 正文对比度不低于 4.5:1。
- 主要点击目标不小于 44×44 逻辑像素。
- 支持字体放大至 200%、屏幕阅读器、高对比度、深浅色和减少动画。
- 提供静态宠物模式，允许关闭声音、粒子、晃动和闪烁。
- 不使用快速闪光动画。
- Windows 与 macOS 保持相同数据模型和同步语义。
- Windows 使用托盘，macOS 使用菜单栏。
- 支持 Windows 高 DPI、macOS Retina、Spaces 和多显示器。
- 重复启动时聚焦已有实例，避免数据库竞争。
- 安装包签名；macOS 完成签名和 notarization。
- P0 支持 Windows 10 22H2、Windows 11 x64，以及 macOS 13 及以上的 Apple Silicon 与 Intel。
- Windows 原生 ARM64 列入 P1，P0 通过兼容层验收。

移动端：

- iOS 使用 Widget、Live Activity、通知和应用内宠物，不承诺全局悬浮。
- Android 悬浮窗默认关闭，并解释系统权限。
- 移动端延续宠物身份、成长、任务和专注状态，不复制桌面自由移动行为。

## 13. 非功能要求

### 13.1 性能

- 快捷录入暖启动 P95 不超过 300ms。
- Todo Pet 展开小窗 P95 不超过 200ms。
- 本地任务操作提供即时反馈。
- 参考设备上应用空闲平均 CPU 目标低于 1%。
- 参考设备上内存目标低于 300MB。
- 紧凑宠物待机默认 10 至 15 FPS，交互短动画最高 30 FPS。
- 减少动画模式为静态或 0 至 10 FPS。
- 不可见窗口停止动画和复杂布局。
- 低电量或节能模式降低粒子、阴影和帧率。
- 不使用常驻大模型推理循环或高频天气轮询。

每次新增角色和动画包必须测量宠物开启与隐藏状态相对基线的 CPU、内存、GPU 和电池差异。

### 13.2 同步、提醒与计时

- 本地修改后 1 秒内启动飞书同步。
- 网络正常时飞书修改一致时间 P95 不超过 10 秒。
- 事件可用时远端变化到达 P95 目标不超过 30 秒。
- 常规同步成功率不低于 99.9%。
- 后台提醒触发误差不超过正负 1 分钟。
- 专注计时跨睡眠、时区变化和重启保持真实持续时间。
- 静默数据丢失或静默覆盖为 0。

### 13.3 可靠性与安全

- 无崩溃会话占比不低于 99.5%。
- 离线队列、专注和允许的自动化跨重启保留。
- 权限判断由确定性权限引擎执行。
- 凭据不暴露给模型或渲染层。
- 文件、浏览器、终端、剪贴板和截图有范围边界测试。
- 研究与行动使用不同工具白名单和新的权限检查。
- Agent 不能自行开启全权限。
- 宠物进程不能修改权限、凭据和审计存储。
- 第三方工具和内容包必须声明来源、版本和权限。
- 奖励、日记和提醒事件必须幂等。

## 14. 指标

北极星指标：**周有效执行用户数（WEAU）**——七天内至少在三个自然日使用产品，且累计完成不少于五项任务或三轮有效专注。

### 14.1 核心指标

| 指标 | Beta 目标 |
| --- | ---: |
| 首次使用 10 分钟内创建或导入任务 | 不低于 80% |
| 首日完成“创建—开始—完成”闭环 | 不低于 60% |
| 飞书目标用户首日完成连接 | 不低于 70% |
| 启用 AI 用户完成首次对话操作 | 不低于 60% |
| 快捷创建任务中位耗时 | 不超过 5 秒 |
| 从 Todo Pet 完成或推迟任务的操作次数 | 不超过 2 次 |
| Todo Pet 周使用率 | 不低于 65% |
| 从 Todo Pet 开始专注的周用户比例 | 不低于 35% |
| D7 留存 | 不低于 35% |
| D30 留存 | 不低于 20% |
| 晨报“有帮助”比例 | 不低于 70% |

### 14.2 守护指标

- 因提醒过多关闭全部通知的用户不高于 15%。
- 主动消息立即关闭率。
- 宠物被临时隐藏或完全关闭的比例。
- 宠物遮挡、抢焦点、位置丢失和误触投诉。
- 待机 CPU、内存、GPU 和电池影响。
- Agent 误操作、未确认执行和错误同步数量。
- 宠物渲染崩溃与静态降级比例。

指标优先本地汇总，允许用户关闭遥测。埋点不得包含任务正文、密钥、精确位置或未脱敏对话。

## 15. P0 发布验收标准

### 15.1 任务与同步

1. 未登录、未连接飞书、未配置 AI 时，本地任务、Todo Pet 和专注完整可用。
2. 用户可在任意应用中通过快捷键创建任务。
3. 本地和飞书任务在主应用与 Todo Pet 中不重复、不丢失并标明来源。
4. P0 公布的飞书字段可双向同步。
5. Todo Pet 创建、完成、重开或修改飞书任务后在 1 秒内启动同步。
6. 离线修改跨应用重启后继续同步。
7. 同字段冲突不会被静默覆盖。
8. 飞书任务可加入私人 Today 而不修改远端截止日期。
9. 会签、或签、单负责人和只读成员的完成语义通过真实租户测试。
10. 飞书 App ID、Secret 和 Token 可安全复用，重启后不要求重复输入。

### 15.2 Todo Pet

11. 旧悬浮球和胶囊已从用户可见设置与运行路径移除。
12. Todo Pet 在 Windows 与 macOS 打包版中可出现、置顶、拖动和恢复位置。
13. 多显示器断开后宠物回到可见区域。
14. 首次展开进入“全部”，后续恢复最后焦点。
15. 悬停达到默认 1 秒后预览，鼠标离开后关闭。
16. 点击展开后鼠标离开不关闭。
17. 双击打开主应用且无单击竞态。
18. 今日任务垂直轮播，鼠标停留暂停。
19. 当前展示任务和完成、推迟、专注动作始终绑定同一 ID。
20. 右键菜单、隐私、安静、隐藏和停止 Agent 可用。
21. 宠物不抢焦点，透明区域不阻塞桌面操作。
22. 动画失败降级静态宠物，不恢复旧悬浮形态。
23. 全屏、屏幕共享、系统勿扰和安静时段不产生非必要主动打扰。
24. 减少动画、键盘、屏幕阅读器和高对比度通过验收。

### 15.3 专注与陪伴

25. 番茄钟、正计时、暂停、恢复、休息和任务绑定可用。
26. 睡眠、唤醒、重启和时区变化不会造成计时漂移或重复奖励。
27. 专注结束通知在宠物不可见时仍能送达且不重复。
28. 模型或天气失败不影响任务、专注和基础宠物动作。
29. 晨间简报在 AI 不可用时仍能生成。
30. 提醒遵守频率预算、安静条件和“为什么提醒”说明。

### 15.4 Agent 与安全

31. Todo Pet 小窗支持流式 Markdown、停止、滚动和会话保持。
32. 单条及批量任务增删改查通过共享任务工具执行。
33. 批量、删除和飞书外部写入在标准模式下正确预览或确认。
34. 操作预览准确展示数量、来源、原值和新值。
35. 所有可逆任务操作提供撤销。
36. 权限测试中不存在未授权工具调用。
37. 全权限不能由模型、聊天、宠物动作、插件或自动化自行开启。
38. 全权限有效期、锁屏、重启、撤权和停止规则通过测试。
39. 文件、浏览器、终端、剪贴板和截图符合类型化契约和永久硬边界。
40. 模型数据范围、一次性授权和即时撤权通过测试。
41. 提示注入不能让研究内容直接形成可执行参数。
42. 修改型工具调用全部生成 Agent 不可篡改的审计记录。
43. 全局停止后不再开始新 Agent 调用，但任务同步、提醒和专注继续运行。

### 15.5 平台与质量

44. Windows 与 macOS 均通过安装、升级、卸载保留数据、开机启动和系统权限恢复。
45. Todo Pet 在高 DPI、Retina、Spaces、多显示器和全屏场景通过验收。
46. 类型检查、单元、组件、端到端和真实打包应用测试全部通过。
47. 不存在已知静默数据丢失、静默覆盖或成功状态伪造。
48. 空闲 CPU、内存和宠物展开延迟达到第 13 节门槛。

## 16. 开发与验收顺序

### Gate A：可靠任务核心

本地数据模型、核心视图、搜索、提醒、循环、离线、回收站、撤销、快捷录入和草稿恢复。

### Gate B：Todo Pet 桌面壳

唯一宠物窗口、静态角色、置顶、拖动、多显示器、状态机、悬停、离开、点击、双击、右键、隐私、减少动画和旧悬浮迁移。

### Gate C：任务与飞书

Todo Pet 五个入口、全部与 Today、轮播、任务操作、飞书授权、同步、队列、冲突、权限与真实账号验收。

### Gate D：专注与确定性陪伴

番茄钟、正计时、休息、恢复、系统通知、晨报、注意力预算、天气和生活提醒。

### Gate E：任务 Agent

模型接入、流式 Markdown、任务问答、单条与批量 CRUD、操作预览、Persona、数据范围、审计和模型降级。

### Gate F：广权限 Agent

文件、沙箱终端、独立浏览器、基础自动化、交互式全权限、紧急停止和安全测试。

### Gate G：成长与长期陪伴

P1 的成长、奖励、小窝、装扮、日记、关系记忆、环境音和跨设备档案。

前一 Gate 未达到数据可靠性与安全门槛，不进入下一 Gate 的公开测试。每个 Gate 都必须保持可运行、可打包和可回滚。

## 17. 主要风险

| 风险 | 缓解措施 |
| --- | --- |
| P0 范围过大 | 按 Gate 分阶段交付，先保证任务事实和宠物壳 |
| 宠物变成干扰源 | 注意力预算、硬性静默、隐藏和主动程度设置 |
| 宠物喧宾夺主 | 所有成长功能必须服务任务执行闭环 |
| 常驻资源过高 | 帧率分级、不可见暂停、性能发布门禁 |
| 悬浮窗口抢焦点或遮挡 | 透明命中区域、焦点测试、贴边和隐藏入口 |
| 飞书字段无法完整映射 | 字段能力矩阵和“仅本地”标识 |
| AI 误解批量范围 | 确定性查询、差异预览和确认 |
| 提示注入 | 研究行动隔离、类型化工具和权限引擎 |
| 全权限造成破坏 | 本机开启、范围时效、审计和紧急停止 |
| 通知疲劳 | 预算、安静时段、连续忽略降频 |
| 模型成本不可控 | 预算、次数、超时和循环熔断 |
| 重复业务状态 | 任务、专注、提醒、权限和 Persona 只保留单一事实来源 |
| 养成造成心理负担 | 无死亡、无衰退、无断签惩罚、无强制喂养 |
| 产品变成通用 Agent | 默认入口和核心指标始终围绕任务执行 |

## 18. 已确定的产品决策

- 核心用户为个人贡献者，产品面向普通个人用户，不建设独立企业版。
- Todo Pet 是唯一桌面悬浮形态，完全替代旧悬浮球与胶囊。
- 用户可以隐藏或关闭 Todo Pet，但不能切回旧悬浮形态。
- 完整主应用继续保留。
- 首只宠物使用原创软萌任务精灵，推荐 2D 或 2.5D。
- 宠物不会死亡、生病或因离线衰退。
- 不提供强制喂养、断签惩罚和情感绑架。
- 首次展开默认“全部”，后续记住最后焦点。
- 今日任务上下轮播，鼠标停留时暂停。
- 悬停默认 1 秒展开，悬停触发的预览在鼠标离开后关闭。
- 点击展开不会因鼠标离开关闭，双击打开主应用。
- Todo Pet 始终置顶和自由拖动由用户控制。
- 小窗内可直接完成 Markdown 流式 Agent 对话。
- AI 完全可选，模型不可用时基础能力正常。
- 任务、飞书、天气、计时和权限不得由模型猜测。
- 飞书保存团队事实，本产品保存私人计划。
- 飞书修改后立即同步，只有远端确认才标记已同步。
- 宠物与 Agent 共用身份、记忆和权限体系。
- 标准模式分级确认；P0 可开启交互式全权限。
- 全权限仍不能读取明文密钥、自行扩权或关闭审计。
- P1 才开放受限范围的无人值守全权限和自动长期关系记忆。
- 默认飞书连接采用零服务器 personal-direct；已有应用使用 existing-direct；Relay 不是默认依赖。
- P0 飞书范围以本 PRD 字段与操作矩阵为准。
- 移动端延续宠物身份和状态，但不强行复制桌面悬浮行为。
