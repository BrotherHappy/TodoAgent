# Todo Pet 产品与体验设计文档

> 文档状态：Draft v0.1<br>
> 更新日期：2026-08-14<br>
> 适用产品：Todo Agent（Windows / macOS，后续扩展 iOS / Android）<br>
> 目标读者：产品、设计、动画、客户端、Agent、测试，以及负责实现本功能的 AI

## 1. 文档目的

本文档定义 Todo Pet 的产品定位、功能范围、视觉方向、交互规则、主动提醒策略、养成系统和版本优先级。

Todo Pet 不是一个与 Todo Agent 并列的新应用，而是 Todo Agent 的宠物化交互模式。后续实现不得只把悬浮球替换成一张宠物图片，也不得把它做成脱离任务管理的养成游戏。

与本文配套的工程规范见 [TODO_PET_IMPLEMENTATION_SPEC.md](./TODO_PET_IMPLEMENTATION_SPEC.md)。

## 2. 一句话定义

> Todo Pet 是住在桌面上的任务伙伴：平时是一只温馨的宠物，需要时是番茄钟、提醒助手，以及能够执行任务操作的 AI Agent。

核心关系不是“用户必须照顾宠物”，而是：

> 用户在照顾好自己的任务、时间和生活时，宠物也随之成长。

## 3. 背景与机会

Todo Agent 已具备本地任务、飞书同步、提醒、悬浮窗口、番茄专注基础、Agent 对话和桌面权限等能力。Todo Pet 可以把这些相对工具化的能力统一为一个具备身体、性格和关系记忆的可见化入口。

市场上已经存在三类相关产品：

1. 以 QQ 宠物、Tamagotchi 为代表的养成宠物。
2. 以 Desktop Goose、Shimeji、eSheep 为代表的桌面宠物。
3. 以 Finch、Focus Friend、Weyrdlets、Habitica、Forest、Spirit City 为代表的宠物化生产力产品。

Todo Pet 的机会在于把三类产品的优点结合起来，并利用 Todo Agent 已有的任务和 Agent 能力形成差异：

- 比桌面宠物更有用，因为它能操作真实任务。
- 比普通 TODO 更温暖，因为任务行为会形成宠物动作、成长和共同回忆。
- 比纯 AI 聊天助手更具存在感，因为它常驻桌面且有可理解的状态。
- 比传统养成游戏更轻松，因为它不通过死亡、饥饿或负罪感逼迫用户上线。

## 4. 产品目标

### 4.1 用户目标

- 让用户更容易开始下一件任务。
- 降低任务提醒的冷硬感和压力。
- 让番茄专注过程更有陪伴感和可见成果。
- 在不打断工作的前提下提供任务、天气和生活提醒。
- 让用户可以直接通过宠物对话完成任务增删改查和重新规划。
- 让长期完成的任务沉淀为宠物成长、日记、收藏和家园。

### 4.2 产品目标

- 建立 Todo Agent 独有的视觉和情感识别度。
- 提高悬浮入口的日活跃率和番茄钟使用率。
- 提高任务按时完成率和次日规划率。
- 建立可扩展的宠物角色、动作、装扮和内容体系。
- 为移动端 Widget、灵动岛、Live Activity 和桌面组件预留统一宠物状态。

### 4.3 非目标

- 第一阶段不做大型养成游戏。
- 第一阶段不做开放世界或复杂社交社区。
- 不把宠物喂养变成用户的新一组待办。
- 不以广告、抽卡或高压连续签到为核心循环。
- 不让宠物代替完整的 Todo Agent 主页面。
- 不允许宠物在未经授权时执行高风险 Agent 操作。

## 5. 设计原则

### 5.1 工具优先，宠物增温

宠物必须帮助用户完成真实任务，而不能成为主要干扰源。每个养成功能都应能回答：“它如何帮助用户开始、坚持、完成或回顾任务？”

### 5.2 温和而不操纵

- 宠物不会死亡。
- 宠物不会因为用户数日未登录而生病。
- 不使用哭泣、责怪、失望等方式制造负罪感。
- 允许中断连续记录、补签或休假。
- 奖励休息和合理节奏，而不只奖励工作量。

### 5.3 外围感知优先

宠物优先通过动作、姿态、服装和小图标传达状态。只有临近截止、严重天气或用户明确设定的事项才升级为系统通知。

### 5.4 可控的主动性

用户能够控制主动程度、提醒严格度、安静时间、允许的信息类型和每天的主动交流上限。

### 5.5 本地能力不依赖模型

宠物待机、拖动、番茄钟、任务提醒、基础天气展示和预设对话必须在大模型不可用时继续工作。

### 5.6 真实状态优先

任务、飞书同步、天气、番茄计时和系统权限必须来自权威数据源。大模型不得猜测这些状态。

### 5.7 渐进披露

默认只显示宠物和当前最重要的信息。详细任务、Agent 对话、宠物小窝和设置通过展开窗口或主页面进入。

## 6. 目标用户与场景

### 6.1 主要用户

- 长时间使用 Windows 或 macOS 的个人贡献者。
- 需要管理大量个人和飞书任务的人。
- 容易拖延、难以开始任务或需要轻度外部陪伴的人。
- 在家工作、独立创作、学习或研究的人。
- 喜欢可爱、治愈、低压力交互，但不希望工具过度游戏化的人。

### 6.2 高频场景

- 早晨打开电脑，快速了解天气和今日任务。
- 不知道下一步做什么，请宠物帮助选择或重新规划。
- 从悬浮宠物直接开始某项任务的番茄钟。
- 在不打开主窗口的情况下完成、延期或新增任务。
- 飞书任务修改后立即查看同步状态。
- 连续工作后收到喝水、远眺或伸展提醒。
- 与宠物对话，批量整理任务或搜索资料。
- 下班前回顾当天并生成宠物日记。

## 7. 产品模型

Todo Pet 由三个相互协作、但可独立降级的层组成：

### 7.1 桌面宠物层

负责：

- 角色形象和动画。
- 置顶、拖动、点击、悬停、右键和拖放。
- 当前情绪、动作、天气服装和轻提示。
- 无模型时的基础陪伴。

### 7.2 效率伙伴层

负责：

- 当前任务展示。
- 全部任务和今日任务。
- 番茄钟、休息、专注统计。
- 截止提醒、生活提醒和天气提醒。
- 奖励、成长、日记和家园。

### 7.3 Agent 化身层

负责：

- Markdown 和流式对话。
- 任务增删改查、批量整理和重新规划。
- 飞书任务和同步操作。
- 网页研究、文件、剪贴板等已授权工具。
- 人格、关系记忆和主动交流内容。

大模型不可用时，前两层必须正常运行，第三层显示明确的离线或未配置状态。

## 8. 核心体验循环

```mermaid
flowchart LR
    A["选择一项任务"] --> B["宠物进入对应工作动作"]
    B --> C["完成一轮专注"]
    C --> D["获得成果、亲密度或收藏"]
    D --> E["更新任务与专注记录"]
    E --> F["宠物日记记录共同经历"]
    F --> A
```

任务类型与宠物表现示例：

| 任务类型 | 专注动画 | 完成成果 |
|---|---|---|
| 学习 / 阅读 | 看书、记笔记 | 书页、知识卡、书架物品 |
| 开发 / 写作 | 敲键盘、画图 | 小工具、手稿、家具组件 |
| 调研 | 使用望远镜、翻资料 | 明信片、地图碎片、标本 |
| 整理 / 家务 | 收纳、扫地 | 房间整洁度、收纳物品 |
| 运动 / 健康 | 拉伸、慢跑 | 徽章、运动配件 |
| 沟通 / 会议 | 戴耳机、写便签 | 合作贴纸、纪要卡片 |
| 未分类 | 通用工作桌动作 | 通用星光或纪念卡 |

任务分类应优先使用本地规则，模型只用于可选增强，并允许用户修改分类。

## 9. 信息架构

### 9.1 桌面形态

| 形态 | 说明 |
|---|---|
| 隐藏 | 用户主动隐藏、全屏策略隐藏或应用退出 |
| 紧凑宠物 | 默认桌面形态，仅宠物、状态标记和必要进度 |
| 悬停预览 | 鼠标停留默认 1 秒后出现轻量气泡或胶囊 |
| 展开小窗 | 任务、专注、对话和小窝的完整小窗口 |
| 主页面 | Todo Agent 完整任务管理、设置和 Agent 工作台 |

### 9.2 展开小窗导航

默认包含五个入口，并记住用户最后选择：

1. **全部**：所有未完成任务。
2. **今天**：今天应处理的任务。
3. **专注**：当前任务、番茄钟和休息。
4. **聊聊**：流式 Markdown Agent 对话。
5. **小窝**：宠物状态、成长、装扮、日记和收藏。

首次使用默认进入“全部”。后续折叠、展开和应用重启均恢复上次焦点。

“动态”不再作为一级入口，合并到“小窝 > 日记与动态”。

## 10. 首次使用与领养

### 10.1 触发条件

用户首次启用“宠物模式”时进入领养流程。原悬浮球模式继续保留，用户可随时切换。

### 10.2 流程

1. 选择宠物基础形象。
2. 为宠物命名。
3. 选择性格预设。
4. 选择主动提醒强度。
5. 设置工作时间和安静时间。
6. 选择是否允许天气和城市信息。
7. 选择是否启用关系记忆。
8. 预览桌面效果并完成领养。

### 10.3 默认值

- 性格：温柔陪伴。
- 主动程度：低。
- 非必要主动对话：每天最多 2 次。
- 安静时间：22:00–08:00。
- 悬停展开：1 秒。
- 任务标题：显示。
- 天气：关闭，直到用户设置城市或授权位置。
- 模型记忆：关闭，直到用户明确启用。

用户可以跳过领养流程，直接使用默认宠物。

## 11. 桌面宠物外观与交互

### 11.1 基础行为

- 始终置顶，可在设置中关闭。
- 自由拖动并记忆每台显示器上的位置。
- 靠近屏幕边缘时允许轻微吸附，但不强制。
- 支持锁定位置。
- 支持透明背景和不规则点击区域。
- 支持多显示器和显示器断开后的安全回退。
- 主体不透明度应明显高于现有悬浮胶囊，避免看不清。
- 阴影柔和但轮廓清晰。
- 允许设置 75%–125% 缩放。

### 11.2 指针交互

| 操作 | 默认结果 |
|---|---|
| 单击宠物 | 展开小窗，进入上次使用的入口 |
| 双击宠物 | 打开 Todo Agent 主页面 |
| 悬停 1 秒 | 展开预览；延迟可设置 |
| 鼠标离开悬停预览 | 自动关闭，仅关闭由悬停触发的展开 |
| 拖动宠物 | 移动位置，不触发单击 |
| 右键宠物 | 打开快捷菜单 |
| 抚摸区域往返移动 | 触发开心动作，需有频率限制 |
| 长按宠物 | 打开互动轮盘，可在设置中关闭 |

### 11.3 拖放交互

| 拖入内容 | 行为 |
|---|---|
| 纯文本 | 预览并询问创建任务、搜索或对话 |
| URL | 询问稍后阅读、研究、总结或创建任务 |
| 文件 | 询问附加到任务、总结或创建相关任务 |
| 图片 | 询问识别内容、作为任务附件或研究素材 |
| Todo Agent 内部任务 | 将其设为当前专注任务 |

所有拖放均先预览，不能立即执行高风险动作。

### 11.4 右键菜单

- 开始专注。
- 快速新增任务。
- 查看全部任务。
- 查看今日任务。
- 和宠物聊聊。
- 抚摸或喂零食。
- 安静一小时。
- 今天只提醒重要事项。
- 隐私模式。
- 锁定/解锁位置。
- 切换动作或姿态。
- 临时隐藏。
- 打开主页面。
- 设置。
- 退出 Todo Agent。

## 12. 宠物状态与动作

### 12.1 基础动作

- 站立、坐下、趴下、睡觉。
- 呼吸、眨眼、看向鼠标。
- 小范围走动、跳跃和伸懒腰。
- 被拖起、落下和边缘坐姿。

### 12.2 情绪动作

- 平静、开心、期待、好奇、疑惑、担心、庆祝、疲惫。
- 情绪不得表达对用户的道德评价。
- “担心”只用于临近截止、同步失败或用户明确的健康提醒。

### 12.3 工作动作

- 看书、记笔记、敲电脑、整理、画图、使用望远镜。
- 番茄钟期间动作应平稳、循环自然、低干扰。
- 休息期间可伸展、喝水、散步或短暂玩耍。

### 12.4 系统状态动作

- Agent 思考、流式输出、等待确认。
- 飞书同步、同步成功、同步失败、冲突。
- 离线、模型未配置、权限不足。
- 天气变化和系统勿扰。

## 13. 任务功能

宠物小窗必须支持：

- 查看全部未完成任务。
- 查看今日任务。
- 自动轮播今日任务，默认上下轮播。
- 鼠标停留时暂停轮播。
- 将当前轮播任务设为完成。
- 新建本地任务或飞书任务。
- 修改标题、时间、计划、优先级、项目和标签。
- 完成、恢复、移动到回收站和恢复。
- 查看飞书来源和同步状态。
- 本地修改飞书任务后立即触发同步。
- 对同步失败提供重试和错误说明。
- 从任务直接开始专注。
- 展示当前专注任务并禁止“显示 A、完成 B”的错位。

批量或有歧义的操作通过 Agent 对话完成，并在执行前展示拟操作清单。

## 14. 番茄钟与专注

### 14.1 支持模式

- 25 分钟专注 / 5 分钟短休息。
- 50 / 10。
- 90 / 20。
- 自定义专注、短休息、长休息和循环数。
- 正计时模式。
- 不绑定任务的自由专注。
- 绑定一个 Todo Agent 任务的任务专注。

### 14.2 开始前

- 默认要求选择任务，但允许跳过。
- 显示预计结束时间。
- 允许选择环境音、是否自动开始休息和是否启用勿扰。
- 记住用户上次配置。

### 14.3 专注中

- 宠物进入任务类型对应的工作动画。
- 紧凑形态显示低干扰环形进度。
- 悬停才显示精确剩余时间。
- 隐私模式隐藏任务标题。
- 支持暂停、提前完成、放弃和记录被打断原因。
- 用户暂停时宠物同步暂停工作动作。

### 14.4 休息中

- 宠物引导喝水、远眺、伸展或站立。
- 支持 30–90 秒的轻互动。
- 不提供无限时长小游戏。
- 允许跳过或延长休息。

### 14.5 完成后

- 写入专注时长和关联任务。
- 可一键完成任务或继续下一轮。
- 发放正向奖励，不因中断扣除已有资产。
- 生成本轮小成果或家园制作进度。
- 提供一句不超过两行的反馈。

## 15. 主动提醒与注意力预算

### 15.1 允许的主动场景

- 每日首次打开的早晨简报。
- 用户工作时间开始后仍未选择任务。
- 任务临近截止或已经过期。
- 番茄钟结束。
- 用户持续工作需要休息。
- 飞书同步失败或发生冲突。
- 用户设置的喝水、服药、站立等生活提醒。
- 显著天气变化或严重天气。
- 下班前的日终回顾。
- 低频、非强制的陪伴式小故事。

### 15.2 提醒强度

| 等级 | 呈现 | 场景 |
|---|---|---|
| L0 外围 | 动作、服装、小图标，无气泡 | 普通天气、同步中、一般状态 |
| L1 轻提示 | 无声气泡，可忽略 | 规划建议、喝水、休息、低优先级任务 |
| L2 重要 | 气泡和系统通知，可操作 | 临近截止、同步失败、用户指定提醒 |
| L3 紧急 | 系统通知和可选声音 | 严重天气、用户明确设为强提醒的事项 |

### 15.3 默认频率

- 非必要主动对话每天最多 2 次。
- 同类非紧急提醒至少间隔 2 小时。
- 生活提醒按用户配置，不消耗随机对话额度。
- 用户连续忽略两次非紧急提醒后，当天减少主动程度。
- 用户手动关闭气泡不产生负反馈。

### 15.4 硬性静默条件

- 正在全屏应用或演示。
- 正在会议或屏幕共享，且用户开启相关检测。
- 正在番茄专注。
- 用户最近持续打字或进行高频鼠标操作。
- 系统勿扰开启。
- 当前处于用户安静时间。
- 用户选择“安静一小时”或“今天只提醒重要事项”。

每条主动提醒应可查看“为什么现在提醒我”，并提供稍后提醒、忽略同类和设置入口。

## 16. 天气与生活陪伴

### 16.1 天气能力

- 支持手动城市，不强制精确定位。
- 支持可选系统位置权限。
- 展示当前天气、今日高低温、降水概率和更新时间。
- 严重天气使用独立数据字段，不由模型判断。
- 天气数据超时或失败时显示未知，不生成推测。

### 16.2 天气表现

- 雨天：雨衣、雨伞和少量雨滴。
- 晴天：晒太阳、墨镜或遮阳帽。
- 降温：围巾、缩成一团。
- 雪天：围巾、小雪人。
- 大风：帽子吹歪或抓住物品。
- 夜间：睡衣、台灯和低亮度动画。

### 16.3 生活提醒

- 喝水。
- 站立和伸展。
- 眨眼与远眺。
- 午餐。
- 用户明确设置的服药提醒。
- 停止加班和准备睡觉。
- 通勤前天气与重要任务摘要。

生活提醒不得提供医疗判断，也不得通过摄像头或麦克风推断用户健康和情绪。

## 17. AI 对话与任务 Agent

### 17.1 对话体验

- 在宠物小窗内完成，不强制跳转主页面。
- 支持 Markdown、代码块、列表、表格和链接。
- 支持流式输出和停止生成。
- 内容较长时支持滚动，并保持合理的自动跟随策略。
- 折叠、展开后保留当前会话和滚动位置。
- 支持键盘发送、多行输入和取消执行。

### 17.2 任务能力

- 查询任务。
- 新增、修改、完成、恢复和删除任务。
- 批量操作。
- 重新规划今日或本周任务。
- 拆分任务和生成下一步。
- 关联番茄钟。
- 创建本地任务或飞书任务。
- 显示同步结果和失败原因。

### 17.3 扩展 Agent 能力

沿用 Todo Agent 的权限体系，可选提供：

- 网页搜索和资料整理。
- 打开网页或本地应用。
- 文件读取、生成和修改。
- 剪贴板。
- 屏幕截图和屏幕理解。
- 终端命令。
- 日历、天气及后续连接器。

风险操作必须人工确认；用户可主动开启“全部权限模式”，但界面必须持续显示该模式已开启。

### 17.4 人格预设

- 温柔陪伴型。
- 元气鼓励型。
- 冷静管家型。
- 活泼淘气型。
- 轻微毒舌型。
- 安静陪伴型。

人格参数包括：主动程度、幽默程度、提醒严格度、回复长度、表情使用、称呼方式和情绪表达程度。

## 18. 记忆系统

### 18.1 记忆分层

| 层级 | 内容 | 默认策略 |
|---|---|---|
| 权威事实 | 任务、番茄钟、天气、飞书同步 | 来自业务数据，不作为模型自由记忆 |
| 用户偏好 | 工作时间、提醒方式、常用时长 | 本地保存，可编辑 |
| 关系记忆 | 名字、称呼、喜欢的话题、共同经历 | 默认关闭，用户开启后保存 |
| 短期上下文 | 当前任务、本轮专注、最近对话 | 会话级或短期保存 |

### 18.2 用户控制

- 查看宠物记住了什么。
- 编辑单条记忆。
- 删除单条或全部记忆。
- 暂停长期记忆。
- 设置不同模型的数据发送范围。
- 导出宠物档案和日记。

任务详情、附件正文和文件内容不应自动写入关系记忆。

## 19. 养成、成长与奖励

### 19.1 正向属性

- 亲密度：共同使用和互动积累。
- 好奇心：调研、阅读和新类型任务。
- 知识：学习与总结。
- 活力：合理专注与休息。
- 手艺：创作、开发、整理和专注成果。
- 勇气：完成困难或长期拖延的任务。

属性只增长或保持，不因离线而下降。

### 19.2 奖励来源

- 完成任务。
- 完成一轮专注。
- 做每日规划。
- 完成日终回顾。
- 处理长期过期任务。
- 主动休息并保持合理节奏。
- 完成用户设定的周目标。

奖励应按任务难度和专注时间进行上限控制，避免通过拆分无意义任务刷奖励。

### 19.3 可解锁内容

- 表情、动作和待机姿态。
- 帽子、眼镜、服装和配饰。
- 小窝家具、墙纸、地板和桌面物件。
- 背景音乐和环境音。
- 冒险地图、明信片和纪念品。
- 宠物职业、成长分支和迷你宠物。
- 日记封面、徽章和相册样式。

### 19.4 成长阶段

建议采用轻量阶段：

1. 初识：完成领养和基础引导。
2. 熟悉：解锁更多动作和小窝。
3. 伙伴：形成偏好、职业倾向和关系记忆。
4. 默契：解锁复杂主动协助和成长分支。

成长不应仅由连续登录天数决定，而应综合任务、专注、互动和健康节奏。

## 20. 宠物日记

### 20.1 日记内容

- 当天完成的任务数量和主题摘要。
- 总专注时长和主要任务。
- 宠物当天进行的活动或冒险。
- 获得的物品、动作和成长。
- 用户主动记录的心情或一句话。
- 明天值得关注的一件事。

### 20.2 生成原则

- 使用实际任务和专注数据生成，不编造完成记录。
- 默认隐藏敏感任务正文，只使用标题或脱敏分类。
- 用户可选择纯本地模板日记或模型增强日记。
- 每篇日记可编辑、删除、导出。
- 未配置模型时仍能生成结构化模板日记。

## 21. 宠物小窝

小窝是成长和回忆的承载页，不应成为高频操作的障碍。

包含：

- 宠物档案。
- 当前属性与成长阶段。
- 装扮和动作选择。
- 房间布置。
- 收藏品和徽章。
- 宠物日记。
- 冒险地图。
- 关系记忆入口。
- 本周专注和任务成果。

休息阶段可引导用户进入小窝，但不得强制。

## 22. 声音与环境氛围

- 默认无声音，首次不自动播放。
- 支持宠物轻音效、番茄提示音和环境音分开控制。
- 支持雨声、壁炉、森林、咖啡馆、白噪音等环境音。
- 支持专注时自动淡入、休息时淡出。
- 支持系统媒体键和单独音量。
- 屏幕共享或会议时默认静音。
- 减少感官刺激模式中关闭随机音效和复杂环境动画。

## 23. 视觉方向

### 23.1 推荐角色方向

第一版推荐原创“任务精灵”，而不是普通猫狗：

- 柔软、圆润、低攻击性。
- 身体或尾巴自然融入 Todo Agent 的勾形符号。
- 颜色可随人格和成长变化。
- 可以通过形变表达同步、天气、专注和 Agent 状态。
- 易扩展为研究、创造、整理和冒险等成长形态。

### 23.2 备选方向

1. 复古像素宠物：开发成本较低，具有 QQ 宠物和电子宠物怀旧感。
2. 柔和 2.5D 动物：亲和力高，但换装和动作成本更高。

### 23.3 UI 风格

- 延续 Todo Agent 的柔和 macOS 风格和磨砂玻璃面板。
- 宠物主体保持清晰、饱满和高可见度。
- 气泡和面板可以使用轻透明玻璃，但正文对比度满足可读性。
- 圆角、柔和阴影、低饱和背景和少量蓝紫渐变。
- 避免过度发光、低对比灰字和大面积透明。

### 23.4 尺寸建议

- 紧凑宠物可视主体：64–96 px，用户可缩放。
- 紧凑窗口点击区域：不小于 88 × 88 px。
- 悬停气泡宽度：220–320 px。
- 展开小窗：建议 420 × 520 px，可在 360–480 px 范围响应。
- 触控目标：桌面不小于 32 px，移动端不小于 44 px。

## 24. 文案与人格规范

### 24.1 文案原则

- 简短、具体、可操作。
- 一次只提出一个主要动作。
- 不夸大、不责怪、不道德评价。
- 区分事实、建议和宠物角色表达。
- 重要数据包含时间或来源。

### 24.2 示例

推荐：

- “十点的任务还有 30 分钟，要一起开始一轮专注吗？”
- “外面两点后可能下雨，我把伞准备好了。”
- “飞书还没同步成功。你可以重试，或者先看看错误原因。”
- “今天已经专注 90 分钟了，要不要先远眺一会儿？”

不推荐：

- “你怎么又拖延了？”
- “你不完成任务我会很难过。”
- “天气肯定会下雨。”（没有权威天气数据）
- “我已经帮你删除了所有任务。”（未经确认）

## 25. 隐私、安全与权限

- 宠物模式不默认增加任何系统权限。
- 天气优先允许手动城市，精确位置单独授权。
- 摄像头、麦克风、屏幕、文件和终端分别授权。
- 高风险 Agent 操作显示操作对象、影响和确认按钮。
- “全部权限模式”持续显示明显状态，可一键关闭。
- API Key、飞书 App ID 和 Secret 使用系统安全存储或本地加密存储。
- 宠物关系记忆默认关闭。
- 屏幕共享时默认隐藏任务标题和对话内容。
- 提供“立即安静”“立即隐藏”和“停止 Agent”三个随时可用的安全出口。
- 宠物日记、对话和记忆支持完整删除和导出。

## 26. 无障碍

- 遵循系统“减少动态效果”。
- 提供静态宠物模式。
- 提供高对比度和更大字体。
- 所有动作信息必须有文本等价表达。
- 宠物和按钮具有可读的辅助功能名称。
- 不使用只靠颜色传达的同步或任务状态。
- 支持完整键盘操作。
- 支持关闭声音、粒子、晃动和闪烁。
- 不使用快速闪光动画。

## 27. 性能与平台要求

### 27.1 性能目标

- 待机动画采用节能帧率。
- 没有交互时暂停不可见面板和复杂特效。
- 不因宠物常驻持续调用大模型或天气接口。
- 天气和主动提醒采用缓存与定时调度。
- 全屏应用、低电量或系统节能模式下降级动画。
- 宠物渲染故障时回退为现有悬浮胶囊，而不是导致应用不可用。

### 27.2 Windows / macOS

- 始终置顶、拖动、透明背景、多显示器和开机启动。
- 打包版权限和 IPC 行为必须分别验证。
- macOS Spaces、全屏和 Dock 行为需单独测试。
- Windows 缩放、任务栏、多显示器和 SmartScreen 场景需单独测试。

### 27.3 iOS / Android 预留

- 宠物档案、成长、日记、当前任务和番茄状态可跨端同步。
- iOS 使用 Widget、Live Activity、通知和应用内宠物，不承诺全局悬浮。
- Android 可根据平台权限提供悬浮窗，但必须默认关闭并解释权限。
- 移动端不复制桌面全部自由移动行为，而保持同一角色和状态。

## 28. 异常和降级

| 异常 | 用户体验 |
|---|---|
| 模型未配置 | 宠物和本地功能正常；对话页说明如何连接模型 |
| 模型请求失败 | 保留已输出内容，支持重试，不伪造结果 |
| 天气失败 | 保留最后更新时间，超时后显示未知 |
| 飞书未登录 | 飞书任务入口显示连接引导，本地任务正常 |
| 飞书同步失败 | 显示待同步和重试，不假装成功 |
| 动画资源失败 | 回退默认静态姿态或现有悬浮胶囊 |
| 数据迁移失败 | 不覆盖旧数据，提示恢复或导出 |
| 多显示器断开 | 将宠物移回主显示器安全区域 |
| 权限被撤销 | 停止相关能力并说明，不反复请求 |

## 29. 成功指标

### 29.1 核心指标

- 启用宠物模式后的 7 日和 30 日留存。
- 从宠物入口开始番茄钟的用户比例。
- 每周使用宠物完成任务操作的用户比例。
- 宠物提醒后在合理时间内开始任务的比例。
- 日终回顾和宠物日记查看率。

### 29.2 守护指标

- 宠物被临时隐藏、永久关闭或卸载的比例。
- 主动消息立即关闭率。
- 提醒静音率和“不要再提醒”比例。
- 待机 CPU、内存和电池影响。
- 宠物遮挡、抢焦点和位置丢失投诉。
- Agent 误操作、未确认执行和错误同步数量。

指标应优先本地汇总，并允许用户关闭遥测。

## 30. 版本规划

### P0：宠物模式 MVP

- 单只原创宠物和 20–30 个核心动作。
- 置顶、拖动、位置记忆、悬停展开、离开关闭和右键菜单。
- 全部、今天、专注、聊聊、小窝入口及焦点记忆。
- 今日任务上下轮播和悬停暂停。
- 任务绑定番茄钟。
- 本地任务和飞书任务基础操作。
- 流式 Markdown Agent 对话。
- 早晨简报、截止提醒、同步状态和基础天气换装。
- 安静、隐私、节能和减少动画模式。
- 模型不可用时的完整本地降级。

### P1：关系和成长

- 命名和人格设置。
- 亲密度、技能和成长阶段。
- 任务分类对应工作动作。
- 奖励、装扮、小窝和收藏。
- 本地模板日记和模型增强日记。
- 主动提醒注意力预算。
- 用户偏好与可选关系记忆。
- 环境音和休息引导。

### P2：内容和长期循环

- 成长分支和宠物职业。
- 冒险地图、明信片和迷你宠物。
- 季节内容和更多角色。
- 更完整的日记、相册和长期回顾。
- 共享专注和好友串门。
- 移动端 Widget 和状态同步。

### P3：开放生态

- 宠物皮肤和动作包。
- 安全的宠物内容 SDK。
- 社区角色和主题市场。
- 可选多人空间和共同家园。

## 31. MVP 发布门槛

P0 上线前必须满足：

- 宠物在 Windows 和 macOS 打包版中可正常出现、拖动、置顶和恢复位置。
- 鼠标悬停、离开、单击、双击、右键和拖动之间不存在冲突。
- 当前显示任务与完成动作严格一致。
- 番茄钟重启后可恢复或明确结束，不丢失记录。
- Agent 对话支持流式 Markdown 和滚动。
- 模型、天气和飞书失败时均有正确降级。
- 宠物不会在全屏、屏幕共享和静默条件下随机打扰。
- 所有高风险 Agent 操作经过确认。
- 支持减少动态效果和完全关闭宠物模式。
- 完成单元、组件、端到端和真实打包应用测试。

## 32. 需要产品确认的开放决策

以下给出推荐默认值，后续头脑风暴时可逐项确认：

| 决策 | 推荐默认 |
|---|---|
| 第一只宠物 | 原创软萌任务精灵 |
| 美术表现 | 2D / 2.5D，非高成本 3D |
| 宠物模式关系 | 作为现有悬浮模式的可选外观，不强制替换 |
| 主动程度 | 默认低，每日最多 2 次非必要对话 |
| 养成压力 | 无死亡、无离线衰减、无强制喂养 |
| 奖励重点 | 共同经历、装扮和家园，高于纯积分 |
| 番茄中断 | 不扣已有资产，记录中断原因即可 |
| 天气位置 | 默认手动城市，精确定位可选 |
| 关系记忆 | 默认关闭，用户明确开启 |
| 社交 | P2 以后再做，不进入 MVP |
