# Todo Agent 全量验收矩阵

最后更新：2026-08-15（Todo Pet 原生桌面形态、当前授权档案、真实模型与飞书自动写回证据汇总）

本表只记录可复现的验收项、测试任务前缀与结果；不记录用户任务内容、账号、Token、App Secret 或模型密钥。

## 执行规则

- 所有真实写入均只使用 `Codex验收-...` 前缀的测试任务。
- 本轮创建的本地验收任务均已移入本地可恢复回收站；飞书验收任务不做不可逆远端删除，除非用户在当时再次确认。
- 本地状态、飞书远端状态和 Agent 最终回复分别核对；`pending` 绝不写成“已同步”。
- 每个核心流程按新建 → 编辑 → 完成 → 重开 → 再完成（或等价可逆恢复）验证；真实 UI、隔离 E2E 与服务边界测试互为补充。

## 当前已知边界

1. 飞书 Task V2 `my_tasks` 列表只保证“我负责”的范围。列表暂时缺席不会被当作远端删除，产品已采取保守保护策略。
2. 没有全局飞书 Tasklist 选择器；飞书清单只能通过显式 `source.tasklist` binding 表示，不能由本地项目或列表猜测。
3. 当前未直接操作飞书客户端做反向日期编辑，也未在真实档案切断网络；对应字段、队列、冲突与重启场景由 Mock API 回归验证。
4. 当前 macOS 包未做 Developer ID 签名/公证；Windows 实机打包和多显示器/全屏观感仍需在对应设备补验。
5. 飞书验收记录因未获永久删除授权而保留；本地验收记录仅移入可恢复回收站。
