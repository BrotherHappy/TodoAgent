## 1. 状态口径

| 标记       | 含义                                                               |
| ---------- | ------------------------------------------------------------------ |
| 已实现     | 已有可运行代码和相应自动化测试，可进入人工验收                     |
| 待外部验证 | 协议与产品流程已实现，但必须使用真实账号、凭据、设备或签名环境验收 |

## 3. 已实现的关键安全边界

- 渲染层只可调用类型化白名单接口；不暴露 Node、通用 IPC 或 Electron 对象。
- 飞书 Token、每位用户专属 App Secret 和模型 API Key 使用系统安全存储；普通设置只保留凭据引用，日志、状态、IPC 和导出不含明文凭据。
- 本地任务不会因连接飞书而自动上传；私人计划、排序、专注等字段不进入飞书写入载荷。
- 模型只能提出严格 Schema 的工具调用，不能直接写本地数据；调用在执行前重新核对参数、目标、风险、基础版本和授权状态。
- 关闭任务标题与时间数据范围后，任务只以不透明本地 ID 和 `redacted` 标记进入模型；附件元数据与文本当前一律不进入模型。
- 网页、HTTP 和网络命令输出会被标记为不可信；同一轮研究后不能直接执行写入、命令或外部动作，必须等待用户下一条消息明确确认。
- 批量、外部和高风险动作需要确认或命中有效的精确临时授权；R4 禁区在全权限模式下也拒绝。
- 文件工具固定在 Agent 工作区内，并校验规范路径、符号链接和硬链接；网页读取阻止凭据 URL、私网目标和未复核重定向。
- 全局停止会阻止新的 Agent 工具调用并撤销临时全权限，但不停止本地提醒和飞书一致性队列。

这些边界已有单元/集成测试覆盖，但发布前仍应在实际打包应用、macOS 权限弹窗和 Windows 安全环境中重复验证。

## 4. 当前明确不应宣称完成的能力

以下能力在 PRD 中有目标或预留，但当前版本不应出现在发布宣传的“已支持”清单中：

- 独立可交互 Agent 浏览器、用户登录态浏览器和完整网页自动化。
- 容器或虚拟机级终端沙箱，以及任意宿主机权限的 OpenClaw 等价能力。
- MCP、Skills/插件、多 Agent、远程设备、桌面应用控制、邮件/日历/消息连接器。
- 可长期后台运行的自定义无人值守 Agent 工作流。
- 自动形成的长期关系记忆、语义检索、本地模型与多模型路由。当前版本只保存用户明确批准的可控记忆。
- 产品账号、跨设备云同步、完整移动端和移动推送。
- 经过签名、公证、自动更新和双平台全矩阵验证的公开发行版。

- [ ] 重启后复用已有专属应用，重新授权不重复创建；普通设置、状态、日志、IPC 和导出不含 Secret 或 Token。
- [ ] 标题、描述、开始、截止、完成/重开、创建和删除的双向写入，与飞书界面逐项一致。
- [ ] 离线编辑跨重启保留；恢复网络后幂等收敛，不重复创建。
- [ ] 同一字段并发修改进入冲突，不静默覆盖；三种处理结果都正确。
